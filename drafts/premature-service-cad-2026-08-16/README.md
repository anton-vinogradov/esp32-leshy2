# Premature service-CAD experiment

- Archived: 2026-08-16
- Status: **noncanonical discarded experiment; no implementation input**
- Superseding decision: [`DEC-0032`](../../docs/review/decisions/DEC-0032-reopen-product-design-before-cad.md)

An uncommitted experiment had started exact service connectors and recovery
footprints before product design and complete architecture selection. Those local
CAD artifacts were discarded rather than promoted. The reviewed, implementation-
neutral requirement that every selected programmable chip retain independent
programming, recovery and diagnostics remains active; connector count, format and
pinout are intentionally open.
