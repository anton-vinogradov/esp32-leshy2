# Leshy2

Документация Leshy2 перестраивается с нуля — по одному проверяемому этапу за раз.

## Каноническое состояние

- Журнал ревью находится в [`docs/review/`](docs/review/README.md).
- Каноничны только принятые решения и артефакты со статусом **«Проведено ревью»**.
- Предыдущая документация сохранена в [`drafts/legacy-2026-08-15/`](drafts/legacy-2026-08-15/README.md) и служит только справочным черновиком.
- Существующие файлы tsCircuit и KiCad считаются legacy-артефактами, пока соответствующий этап не пройдёт ревью и не перегенерирует их из новой спецификации.

## Текущее состояние

| Этап | Статус |
|---|---|
| 0. Система ревью и baseline | Проведено ревью |
| 1. Видение и границы | Проведено ревью |
| 2. Возможности и исключения | Требуется решение |
| Последующие этапы | Не начато |

Уже принято: Leshy2 — all-in-one полевой инструмент; все функции исследования безопасности находятся только в **«Лаборатории»** и идут от простых наблюдений к наиболее серьёзным разрешённым тестам. При первичной установке обязателен акт о ненападении. ESP32-C5 владеет тремя nRF24 и IR. Транспорт между MCU намеренно оставлен нерешённым, потому что у ESP32-C5 только один general-purpose SPI-контроллер.
