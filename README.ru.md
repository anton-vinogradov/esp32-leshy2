# Leshy2

Документация Leshy2 перестраивается с нуля — по одному проверяемому этапу за раз.

## Каноническое состояние

- Журнал ревью находится в [`docs/review/`](docs/review/README.md).
- Каноничны только принятые решения и артефакты со статусом **«Проведено ревью»**.
- Предыдущая документация сохранена в [`drafts/legacy-2026-08-15/`](drafts/legacy-2026-08-15/README.md) и служит только справочным черновиком.
- Существующие файлы tsCircuit и KiCad считаются legacy-артефактами, пока соответствующий этап не пройдёт ревью и не перегенерирует их из новой спецификации.

Уже принято: Leshy2 — all-in-one полевой инструмент; все функции исследования безопасности находятся только в **«Лаборатории»** и идут от простых наблюдений к наиболее серьёзным разрешённым тестам. При первичной установке обязателен акт о ненападении.

При запуске все передатчики выключены, каждый Lab-инструмент разоружён, а первая передача использует консервативный профиль. Максимальная TX-мощность доступна только после явного выбора пользователя и никогда не является общим дефолтом.

По `DEC-0005` полная стоимость продукта систематически снижается, но более дешёвая реализация принимается только после доказательства отсутствия потерь функций, характеристик, безопасности, надёжности, автономности, ремонтопригодности и тестируемости.

GNSS не устанавливается на базовую плату. GPS-функции работают с внешним M5Stack Unit GPS v1.1 через отдельный защищённый 5-вольтовый UART Grove-порт по `DEC-0006`.

Для 3× nRF24 и IR принято только **целевое требование владения C5**, а не готовая архитектура. Его реализуемость пока не подтверждена: legacy-топология назначает единственный GP-SPI C5 двум несовместимым ролям. Межпроцессорный транспорт должен быть заменён или отдельно доказан на этапе 3; см. `FND-0001`.
