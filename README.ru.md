# Leshy2

*Читать на: [English](README.md) · **Русский***

**Открытый портативный многодиапазонный РЧ-наладонник — «полевой инструмент», который ты собираешь сам.**

Leshy2 — преемник [esp32-leshy](https://github.com/anton-vinogradov/esp32-leshy), который является прошивочным форком [ESP32-DIV](https://github.com/cifertech/ESP32-DIV). Причина новой платы проста: у ESP32-DIV v2 нет Wi-Fi 5 GHz. Leshy2 это исправляет, переводя весь дизайн на единый мозг **ESP32-C5** (нативный Wi-Fi 2.4 **и** 5 GHz + BLE) и добавляя вокруг заметно больше радио. Цель — максимум возможностей в разумных пределах за честную цену, целевой BOM около **115–150 USD**. Формат остаётся наладонником в духе DIV, только осовремененным. Проект делается открыто, чтобы к нему могли присоединяться.

> 🛑 **Только своё оборудование.** Это учебный инструмент для исследований безопасности и радио. Используй его только на сетях, устройствах и радиоканалах, которыми владеешь или на тест которых есть письменное разрешение. Радиозаконы различаются по странам — проверять и соблюдать их твоя обязанность.

## 🌳 Родословная

Leshy2 стоит на двух проектах:

- **[ESP32-DIV](https://github.com/cifertech/ESP32-DIV)** от CiferTech (MIT) — аппаратный концепт и исток всей линейки.
- **[esp32-leshy](https://github.com/anton-vinogradov/esp32-leshy)** — прошивка-предшественник (наш вариант DIV на ESP32-S3), с которой портируется софт Leshy2.

## 🧰 Что оно умеет

Сгруппировано по тому, что ты реально с ним делаешь. Всё рассчитано на твоё собственное оборудование.

**Разведка / атаки**
- Wi-Fi 2.4 + 5 GHz (ESP32-C5): скан, deauth, флуд beacon/probe, снифф management-фреймов — уровня Marauder.
- 2.4 GHz «сырое» (3× nRF24L01+PA/LNA): параллельный скан всего диапазона, mousejack, анализатор каналов.
- Sub-GHz (CC1101): захват и воспроизведение OOK/FSK пультов и датчиков; «гейгер» активности по RSSI.
- BLE (ESP32-C5).
- IR (TX/RX): клон и воспроизведение пультов.
- NFC (RFID2 через Grove): чтение MIFARE / NTAG.

**Слушать (голосом)**
- Si4732 (только приём): CB 27 MHz, весь HF / коротковолновый, MW / LW (AM / SSB / CW) и FM-вещание 64–108 MHz.
- SA868-U: голос NBFM на 433 / 446 MHz — можно и слушать, и говорить.
- Настоящее аналоговое аудио: line-out → усилитель класса D PAM8302 → небольшой динамик. MCU **не** в аудиотракте.

**Передача**
- Рация SA868-U: голос на 433 / 446 MHz, RX и TX до 2 W (PTT, управление по UART). Мощность TX ограничена регионом / лицензией — 446 PMR максимум 0.5 W ERP; 5 W только на любительском 70 cm при наличии лицензии.
- Meshtastic поверх LoRa (SX1262 на плате): шифрованный текстовый mesh на километровой дальности (+22 dBm). Лимиты мощности по регионам применяются в прошивке.

**Просмотр спектра**
- 3.5″ IPS TFT (ST7796, 320×480) по SPI — большой цветной водопад с яркой подсветкой, читается на улице.
- «Сырой» спектр 2.4 GHz через тракт nRF24; sub-GHz водопад через CC1101.
- Поантенный янтарный TX-светодиод — аппаратный детектор огибающей, честное «в эфире» даже если прошивка зависла, 0 GPIO. RX-светодиода нет (детектор сажал бы чувствительность приёма); активный тракт виден на экране.

**Вспомогательное (на борту)**
- microSD (SPI) для логов PCAP.
- IR TX / RX.
- WS2812 RGB статус-светодиод + buzzer.
- Кнопки + поворотный энкодер.
- GPS (u-blox на шине I²C Grove) для координат / времени.
- Длинный текст набирается на телефоне по BLE (приложение Meshtastic) — бортовой клавиатуры нет.

**Расширяемость (совместимо с M5)**
- **1× порт Grove HY2.0-4P (I²C).** Держит u-blox GPS плюс любые M5 I²C-юниты — RFID2 NFC (0x28), RTC, IMU / компас, сенсоры — по адресам, а при нескольких сразу — через Grove I²C-хаб.
- Поддерживает только M5 **Grove I²C-юниты**. M5 **Caps**, **Modules** и StickC **HATs** используют другие разъёмы и **не** поддерживаются. Модули с выходом DAC не работают (у C5 нет DAC).

| Диапазон | Чип | RX | TX | Что делаешь |
|------|------|:--:|:--:|-------------|
| 2.4 GHz Wi-Fi + BLE | ESP32-C5 | ✓ | ✓ | скан, deauth, флуд beacon/probe, снифф mgmt |
| 5 GHz Wi-Fi | ESP32-C5 | ✓ | ✓ | те же инструменты уровня Marauder на 5 GHz |
| 2.4 GHz «сырое» | 3× nRF24L01+ | ✓ | ✓ | параллельный скан диапазона, mousejack, анализатор |
| 300–928 MHz | CC1101 | ✓ | ✓ | захват / replay OOK / FSK пультов и датчиков, RSSI «гейгер» |
| 433 / 446 MHz NBFM | SA868-U | ✓ | ✓ (≤2 W) | слушать и говорить (голосовая рация, PTT) |
| 27 MHz CB + HF / MW / LW | Si4732 | ✓ | — | слушать AM / SSB / CW КВ и CB |
| 64–108 MHz FM | Si4732 | ✓ | — | слушать FM-вещание |
| LoRa (EU433 / EU868 / US915) | SX1262 (на плате) | ✓ | ✓ (+22 dBm) | Meshtastic шифрованный текст-mesh, км |
| GPS L1 ~1.575 GHz | u-blox (I²C) | ✓ | — | координаты / время (NMEA по I²C) |

Лимиты мощности LoRa в прошивке: EU433 +10 dBm, EU868 +14 dBm, суб-диапазон 869.4–869.65 MHz +27 dBm при 10% duty, US915 +30 dBm с частотным хоппингом.

## 🧩 Архитектура вкратце

![Системная архитектура Leshy2](docs/img/system-diagram.svg)

- **Один мозг:** ESP32-C5 (RISC-V) — нативный Wi-Fi 2.4 + 5 GHz и BLE в одном MCU, и единственный ESP32 с нативным 5 GHz. Прошивка портируется с кодовой базы ESP32-S3 (leshy).
- **Весь бортовой РЧ** — на экранированных модулях с u.FL, выбрано ради снижения рисков первой итерации PCB.
- **Общие шины:** SPI (microSD + бортовой SX1262 + CC1101 + 3× nRF24 + дисплей ST7796, chip-select через дешифратор 74HC138), I2C (Si4732 + u-blox GPS + расширитель PCA9555 + Grove-порт), UART (SA868).
- **8 бортовых антенн:** C5 2.4/5 dual-band, 3× nRF24, CC1101, телескоп Si4732, UHF SA868, LoRa SX1262. Антенны сверху; разъёмы расширителей по бокам или сзади. Общего РЧ-свитча нет, поэтому у каждой цепи своя антенна. (У u-blox GPS своя встроенная антенна на его модуле.)
- **Расширение:** 1 порт Grove I²C (M5 I²C-юниты).
- **Питание:** 2× 18650 в 2S (~7.4 V, ~18 Wh) со своим PMIC — зарядник BQ25xxx + USB-C PD (CH224K) + power-path (работает во время зарядки), buck 5 V/3 A + LDO 3.3 V. Время работы: лёгкий ~9 ч, активный ~3.6 ч, пики TX ~2.5 ч.
- **PCB:** 4 слоя (JLCPCB JLC7628), проектируется в KiCad. Антенны настраиваются вручную по VNA.

Одно радио работает в единицу времени, поэтому шины SPI/I²C/UART общие, а спящие радио выключены; медленные управляющие линии едут на I²C-расширителе (PCA9555). Именно это вмещает столько радио в ~20 рабочих GPIO у C5. См. [docs/pin-budget.md](docs/pin-budget.ru.md).

## ⚖️ Честные ограничения

- **5 GHz только уровня Marauder** — скан, deauth, флуд beacon/probe, снифф. Без захвата WPA-хендшейка, без инъекции, не Pineapple. Для такого нужен Linux, которого мы намеренно избегаем ради времени работы от батареи.
- **27 MHz (и весь HF Si4732) только приём.**
- **Провалы голосового приёма:** ~108–430 MHz и ~480–860 MHz (airband AM 118–137, VHF/UHF NFM вне 433/446). Их покрытие потребовало бы RTL-SDR + мини-Linux — вне области задачи.
- **Не HackRF:** нет сплошного 1 MHz–6 GHz с произвольным TX.
- **Никакого широкополосного глушения** — это незаконно (US Communications Act §333, EU RED) и построено не будет.
- **Железо ещё не собрано** — это стадия проектирования.

## 🙏 Основано на ESP32-DIV

Leshy2 стоит на плечах [ESP32-DIV](https://github.com/cifertech/ESP32-DIV) от CiferTech (MIT, 3.7k звёзд) — щедрого открытого мультитула и самой причины, по которой существует линейка leshy. Leshy2 отдаёт должное этой работе и опирается на неё, а разрабатывается открыто, чтобы приглашать к сотрудничеству сообщество DIV.
