# Leshy2

*Читать на: [English](README.md) · **Русский***

**Открытый портативный многодиапазонный РЧ-наладонник — «полевой инструмент», который ты собираешь сам.**

Leshy2 — преемник [esp32-leshy](https://github.com/anton-vinogradov/esp32-leshy), который является прошивочным форком [ESP32-DIV](https://github.com/cifertech/ESP32-DIV). Причина новой платы проста: у ESP32-DIV v2 нет Wi-Fi 5 GHz. Leshy2 это исправляет, **не выбрасывая зрелый дизайн на ESP32-S3** — S3 остаётся главным мозгом (UI, дисплей, все проводные радио, SD, шины, нативный Wi-Fi 2.4 GHz + BLE), а рядом ставится **сопроцессор ESP32-C5** ради того единственного, чего S3 не умеет: нативный **5 GHz** Wi-Fi (плюс 2.4 GHz, BLE и 802.15.4 / Zigbee / Thread). Два чипа, один полевой инструмент. Цель — максимум возможностей в разумных пределах за честную цену — около **$135–160 в сборе** (~$108–125 электроники; см. [разбор бюджета](docs/bom.ru.md)). Формат остаётся наладонником в духе DIV, только осовремененным, и делается открыто, чтобы к нему могли присоединяться.

> 🛑 **Только своё оборудование.** Это учебный инструмент для исследований безопасности и радио. Используй его только на сетях, устройствах и радиоканалах, которыми владеешь или на тест которых есть письменное разрешение. Радиозаконы различаются по странам — проверять и соблюдать их твоя обязанность.

## 🌳 Родословная

Leshy2 стоит на двух проектах:

- **[ESP32-DIV](https://github.com/cifertech/ESP32-DIV)** от CiferTech (MIT) — аппаратный концепт и исток всей линейки.
- **[esp32-leshy](https://github.com/anton-vinogradov/esp32-leshy)** — прошивка-предшественник (наш вариант DIV на ESP32-S3), с которой портируется софт Leshy2.

## 📌 Статус

**Открытый проект на стадии проектирования. Железа пока нет.**

- Архитектура **зафиксирована** (2026-08-10) — два чипа: мозг ESP32-S3 + сопроцессор ESP32-C5.
- **Схема спроектирована полистно** — питание · MCU+шины · РЧ · аудио · расширение · индикация — как transcribe-ready спеки + чертежи в [hardware/](hardware/).
- **Дальше:** захват листов в KiCad, затем разводка PCB. Proof-of-concept 5 GHz-deauth гоняется на девките C5 **до** заказа платы.
- Ничего ещё не собрано и не проверено на реальном железе. Следи, комментируй и вноси вклад, пока проект обретает форму.

## 🧰 Что оно умеет

Сгруппировано по тому, что ты реально с ним делаешь. Всё рассчитано на твоё собственное оборудование.

**Разведка / атаки**
- Wi-Fi 2.4 GHz (ESP32-S3): скан, **deauth**, флуд beacon / probe, снифф management-фреймов — уровня Marauder.
- Wi-Fi 5 GHz (ESP32-C5): скан, снифф, флуд beacon / probe — 5 GHz-разведка, которой у DIV не было.
- 2.4 GHz «сырое» (3× nRF24L01+PA/LNA): параллельный скан всего диапазона, mousejack, анализатор каналов.
- Sub-GHz (CC1101): захват и воспроизведение OOK / FSK пультов и датчиков на 315 / 433 / 868 / 915 MHz; «гейгер» активности по RSSI.
- Флуд BLE-адвертайзингов + снифф 802.15.4 / Zigbee (ESP32-C5).
- NFC (RFID2 через Grove): чтение MIFARE / NTAG.

**Слушать (голосом)**
- Si4732 (только приём): CB 27 MHz, весь HF / коротковолновый, MW / LW (AM / SSB / CW) и FM-вещание 64–108 MHz.
- SA868-U: голос NBFM на 433 / 446 MHz — можно и слушать, и говорить.
- Настоящее аналоговое аудио: моно line-out → усилитель класса D PAM8302 → динамик + гнездо наушников. MCU **не** в аудиотракте.

**Передача**
- Рация SA868-U: голос на 433 / 446 MHz, RX и TX до 2 W (кнопка PTT, управление по UART). Мощность TX ограничена регионом / лицензией — 446 PMR максимум 0.5 W ERP; 5 W только на любительском 70 cm при наличии лицензии.
- Meshtastic поверх LoRa (SX1262 / E22-900M22S на плате, +22 dBm): шифрованный текстовый mesh на километровой дальности. Лимиты мощности по регионам применяются в прошивке.

**Просмотр спектра**
- 3.5″ IPS TFT (ST7796, 320×480) по SPI — большой цветной водопад на аппаратном верт. скролле, с яркой подсветкой, читается на улице.
- «Сырой» спектр 2.4 GHz через тракт nRF24; sub-GHz водопад через CC1101.
- Поантенный янтарный TX-светодиод — аппаратный детектор огибающей, честное «в эфире» даже если прошивка зависла, 0 GPIO. RX-светодиода нет (детектор сажал бы чувствительность приёма); активный тракт виден на экране.

**Вспомогательное (на борту)**
- microSD (SPI) для логов PCAP.
- WS2812 RGB статус-светодиод + buzzer.
- Кнопки (RESET, BOOT, PTT) + поворотный энкодер; единственный вкл/выкл — master-тумблер.
- GPS (u-blox на плате по UART) для координат / времени.
- Длинный текст набирается на телефоне по BLE (приложение Meshtastic) — бортовой клавиатуры нет.

**Расширяемость (совместимо с M5)**
- **2× порта Grove HY2.0-4P (I²C, 3.3 В).** Держат M5 I²C-юниты — RFID2 NFC, RTC, IMU / компас, сенсоры — по адресам. (u-blox GPS — на плате по UART, не на этой шине.)
- Поддерживает только M5 **Grove I²C-юниты**. M5 **Caps**, **Modules** и StickC **HATs** используют другие разъёмы и **не** поддерживаются.

## 🧩 Архитектура вкратце

![Системная архитектура Leshy2](docs/img/system-diagram.svg)

- **Два чипа.** **ESP32-S3-WROOM-1U-N8R2** (двухъядерный, quad-PSRAM) — **главный мозг**: UI, дисплей, все проводные радио, SD, все шины и нативный Wi-Fi 2.4 GHz + BLE, на полных 38 / 38 GPIO. **ESP32-C5-WROOM-1U** — **чистый сопроцессор** (единственный ESP32 с нативным 5 GHz): добавляет 5 GHz / 2.4 GHz / BLE / 802.15.4, на своей dual-band антенне и ~11 / 20 GPIO. Прошивка портируется с кодовой базы ESP32-S3 (leshy).
- **Линк чип-чип:** выделенный **SPI3 + строб DRDY** (C5 — чистый SPI-slave; DRDY сигналит, когда у него есть данные). C5 не касается общей шины. S3 умеет шить C5 по UART0 (авто-OTA, держит оба образа в синхроне); у C5 к тому же свой USB-C для brick-safe восстановления.
- **Общая шина (S3 FSPI, 80 МГц):** microSD + CC1101 + 3× nRF24 + SX1262 + дисплей ST7796 — chip-select через дешифратор 74HC138. Два I²C-расширителя **PCA9555** держат медленные управляющие линии: 0x20 (управление радио / дисплеем) и 0x21 (PTT, гейты рейлов, выбор SP4T, аудио-джек). Прерывания остаются на прямых ногах: LoRa DIO1, nRF24 IRQ, carrier-sense CC1101.
- **9 антенн:** S3 2.4 GHz (внешняя SMA), C5 dual-band 2.4 / 5, 3× nRF24, CC1101, телескоп Si4732, UHF SA868, LoRa SX1262. Общего РЧ-свитча нет, поэтому у каждой цепи своя антенна (выбор sub-GHz диапазона — через SP4T + четыре матч-сети за единственной антенной CC1101).
- **Дисплей:** ST7796 320×480 IPS по SPI (не 8080 / AMOLED — у C5 нет LCD_CAM), водопад на аппаратном верт. скролле.
- **Два порта USB-C:** J1 → S3 (заряд + данные), J2 → C5 (только данные, brick-safe). Один источник питания — пак заряжается только через J1.
- **Питание:** 2× 18650 в 2S со своим PMIC — **boost-зарядник BQ25887** (заряжает 2S от обычных 5 В USB, без PD), buck MP2315 +5 В, TLV62569 +3V3, отдельный аналоговый рейл TPS7A2033 +3V3 и гейты рейлов, отрубающие спящие радио. Единственный вкл/выкл — жёсткий master-тумблер.

Одно радио работает в единицу времени, поэтому общая SPI-шина и медленные управляющие линии вмещают столько радио в бюджет ног. См. [docs/pin-budget.md](docs/pin-budget.ru.md).

## ⚖️ Честные ограничения

- **5 GHz только разведка** — скан, снифф, флуд beacon / probe. Без инъекции, без захвата WPA-хендшейка, без monitor+inject. Для такого нужен Linux, которого мы намеренно избегаем ради времени работы от батареи. (2.4 GHz deauth работает, на S3.)
- **27 MHz (и весь HF Si4732) только приём.**
- **Одно радио за раз** — РЧ-тракты делят SPI-шину, поэтому спящие радио выключены, пока работает одно.
- **Не HackRF:** нет сплошного широкополосного захвата и произвольного TX.
- **Никакого широкополосного глушения** — это незаконно (US Communications Act §333, EU RED) и построено не будет.
- **Железо ещё не собрано** — это стадия проектирования.

## 🙏 Основано на ESP32-DIV

Leshy2 стоит на плечах [ESP32-DIV](https://github.com/cifertech/ESP32-DIV) от CiferTech (MIT) — щедрого открытого мультитула и самой причины, по которой существует линейка leshy. Leshy2 отдаёт должное этой работе и опирается на неё, а разрабатывается открыто, чтобы приглашать к сотрудничеству сообщество DIV. Если тебе нравится этот проект — сначала поставь звезду и поддержи оригинал.
