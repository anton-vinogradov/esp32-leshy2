# Leshy2 — лист C5 + шины (Лист 2)

*Читать на: [English](c5-buses.md) · **Русский***

ESP32-C5 и как от него расходятся все шины: общая SPI с дешифратором chip-select **74HC138**, I²C (с расширителем медленных сигналов **PCA9555**), UART к SA868, линии `DC`/`CS`/`RESX` дисплея, поворотный энкодер, USB и цепь reset/boot. Схема — в [c5-buses-schematic.svg](c5-buses-schematic.svg), логика ног — в [../../docs/pin-budget.md](../../docs/pin-budget.ru.md).

> ⚠️ Стадия проектирования. **Номера GPIO ниже — предлагаемая карта**, ещё не сверенная с даташитом ESP32-C5. До захвата: boot-уровни strapping-пинов (подтяжки по даташиту), какие ноги дотягиваются до RMT/FSPI/I²C, переиспользование USB/UART-консоли. Функции зафиксированы, номера могут сдвинуться.

## MCU

**U10 — ESP32-C5-WROOM-1U-N8R4** (или -N16R8): одно ядро RISC-V, нативный Wi-Fi 2.4 **и** 5 ГГц + BLE + 802.15.4, **8/16 МБ flash + 4/8 МБ PSRAM в корпусе**. PSRAM держит фреймбуфер 320×480×2 ≈ 300 КБ и рабочий набор порта прошивки. Внутрикорпусной flash/PSRAM занимает GPIO16–22 (не выведены); нативный USB — на GPIO13/14.

**Антенна: вариант -1U выводит РЧ на разъём u.FL** → внешняя двухдиапазонная SMA сверху (это 8-я бортовая антенна). Держать зону запрета меди под u.FL/коаксом, настраивать 2.4 / 5 ГГц на железе. Аппаратный TX-live светодиод отводится от этого фидера (Лист 6).

## Карта GPIO (предлагаемая)

~20 рабочих GPIO (GPIO0–28 минус flash/PSRAM 16–22 минус USB 13/14). **Прямых сигнальных ног = 19; GPIO28 = кнопка BOOT, EN = RESET**; вкл/выкл — **master-тумблер** (Лист 1). Это все 20 — свободной прямой ноги нет (LoRa `DIO1` опрашивается, чтобы уложиться).

| C5 GPIO | Цепь | Напр. | Периферия / примечание |
|:--:|------|:--:|-------|
| GPIO23 | `SPI_SCK` | вых | FSPI (через матрицу GPIO) |
| GPIO24 | `SPI_MOSI` | вых | FSPI |
| GPIO6 | `SPI_MISO` | вх | FSPI |
| GPIO0 | `I2C_SDA` | о-к | внеш. подтяжка 4.7 кОм; I²C-idle=высокий = нормальный boot |
| GPIO1 | `I2C_SCL` | о-к | внеш. подтяжка 4.7 кОм |
| GPIO11 | `UART_TX` → SA868 | вых | UART0-консоль переназначена (прошивка по USB) |
| GPIO15 | `UART_RX` ← SA868 | вх | UART0 |
| GPIO2 | `HC138_A` | вых | ⚠ strap: выбор частоты кварца — boot-подтяжка под кварц модуля (40 МГц = низкий) |
| GPIO3 | `HC138_B` | вых | ⚠ strapping — подтяжка |
| GPIO25 | `HC138_C` | вых | ⚠ strapping — подтяжка |
| GPIO12 | `LCD_DC` | вых | UART0-RX консоль переназначена |
| GPIO8 | `CC1101_GDO0` | вх/вых | RMT (сырой OOK): захват RX и драйв TX-replay |
| GPIO9 | `LoRa_BUSY` | вх | опрос перед каждой командой SX1262 |
| GPIO10 | `IR_RX` | вх | RMT (приём демода) |
| GPIO4 | `ENC_A` | вх | подтяжка; квадратура |
| GPIO5 | `ENC_B` | вх | подтяжка; квадратура |
| GPIO26 | `nRF24_CE` | вых | ⚠ strapping — подтяжка; 3 модуля связаны |
| GPIO7 | `IR_TX` | вых | ⚠ strapping — подтяжка; несущая RMT/LEDC |
| GPIO27 | `WS2812` | вых | ⚠ boot-strap: **обязан быть высоким** на ресете → pull-up; RMT; **сдвигатель на 5 В** (Лист 6) |
| GPIO13 | `USB_D−` | — | нативный USB (прошивка + данные) |
| GPIO14 | `USB_D+` | — | нативный USB |
| GPIO28 | кнопка `BOOT` | вх | boot-strap: низкий → serial download; внутр. + внешн. pull-up |

**Не на прямой ноге:** `LoRa_DIO1` **опрашивается** по SPI (`GetIrqStatus`); `nRF24 IRQ` тоже опрашивается по SPI. Все медленные управляющие линии — на **PCA9555** (ниже), включая добавленные ревью: `RESX` дисплея, enable подсветки, T/R LoRa, аудио-мукс, shutdown усилителя и enable 74HC138.

## Блоки и компоненты

| Ref | Компонент | Роль | Ключевое |
|-----|------|------|-----------|
| U10 | **ESP32-C5-WROOM-1U** (PSRAM) | Мозг + мастер всех шин радио | `+3V3`; цепь EN + boot; USB на 13/14; антенна u.FL |
| U11 | **74HC138** | Дешифратор chip-select 3→8 | `A/B/C` = GPIO2/3/25; `G1`=+3V3, `G2B`=GND; **`G2A` = `HC138_EN`** с PCA9555 (подтянут высоко = выключен на boot) |
| U12 | **PCA9555** | I²C-расширитель под медленные линии | I²C `0x20`; везёт 16 низкоскоростных сигналов ниже |
| SW10 | Энкодер + нажатие | Навигация | `A/B` = GPIO4/5 (прямо); `SW` = PCA9555 |
| J10 | Отвод USB-C данных | Прошивка + данные + консоль | `D−/D+` = GPIO13/14; общий разъём J1 с листом питания |
| — | Развязка | Рейлы C5 | 10 мкФ + 0.1 мкФ на каждый `+3V3`; 1 мкФ на EN |

### 74HC138 — карта chip-select

| Выход | Chip-select | На листе SPI |
|:--:|------|------|
| Y0 | `SD_CS` | microSD |
| Y1 | `CC1101_CS` | sub-GHz |
| Y2 | `nRF24_1_CSN` | 2.4 raw #1 |
| Y3 | `nRF24_2_CSN` | 2.4 raw #2 |
| Y4 | `nRF24_3_CSN` | 2.4 raw #3 |
| Y5 | `LoRa_NSS` | SX1262 |
| Y6 | `LCD_CS` | дисплей ST7796 |
| Y7 | (никто) | **idle / адрес «снять все CS»** |

В каждый момент низкий только один Y. **`G2A` гейтится `HC138_EN`** (выход PCA9555, подтянут **высоко** на boot): дешифратор полностью выключен всё boot/strap-окно, прошивка включает его только когда адресные линии устоялись — это убивает ложный CS, который был бы у всегда-включённого варианта на ресете. Чтобы не говорить ни с кем (шина в покое), прошивка ставит `A/B/C` на **Y7**; краткий транзиент при смене адреса безвреден, т.к. SCK при переключении не тактирует.

### PCA9555 — карта медленных сигналов (I²C, 0 ног хоста)

| Порт | Сигнал | Напр. | Куда |
|:--:|------|:--:|------|
| P0.0 | `ENC_SW` | вх | нажатие энкодера |
| P0.1 | `SA868_PTT` | вых | push-to-talk рации |
| P0.2 | `SA868_PD` | вых | power-down рации |
| P0.3 | `Si4732_RST` | вых | сброс HF-приёмника |
| P0.4 | `LoRa_NRESET` | вых | сброс SX1262 |
| P0.5 | `BUZZER` | вых | активный buzzer (вкл/выкл) |
| P0.6 | `LCD_RESX` | вых | сброс ST7796 |
| P0.7 | `MUX_SEL` | вых | аудио-мукс 2:1 (Лист 4) |
| P1.0 | `BQ_INT` | вх | прерывание зарядника (Лист 1) |
| P1.1 | `BQ_CD` | вых | disable/пауза зарядника (Лист 1) |
| P1.2 | `LoRa_TR` | вых | выбор T/R E22 → RXEN напрямую + TXEN через инвертор (Лист 3) |
| P1.3 | `PAM_SD` | вых | shutdown усилителя динамика (Лист 4) |
| P1.4 | `LCD_BL_EN` | вых | enable драйвера подсветки (вкл/выкл) |
| P1.5 | `RFSW_CTL` | вых | РЧ-свитч полос CC1101 (Лист 3) |
| P1.6 | `HC138_EN` | вых | гейт `G2A` 74HC138 (подтянут высоко на boot) |
| P1.7 | — | — | запас (напр. jack-detect) |

Все 16 портов расписаны, 1 запас. Тайминг-критичные линии сюда не идут — только сбросы, enable, PTT, кнопки и выбор мукса. Заряд батареи читается из **собственного I²C-ADC BQ25887**, отдельная ADC-нога не нужна.

### Кнопки reset и boot

Две физические кнопки на C5; вкл/выкл — **master-тумблер** (Лист 1), **софт-кнопки нет** (у BQ25887 нет ship-mode).

- **RESET (SW_RST)** — момент. между **EN**–GND. На EN — RC сброса по питанию (10 кОм на `+3V3` + 1 мкФ на GND).
- **BOOT (SW_BOOT)** — момент. с **GPIO28** на GND. GPIO28 — strap загрузки C5 (низкий на ресете → serial bootloader) с внутренней подтяжкой; добавить и внешнюю. Держать BOOT + тапнуть RESET = принудительный download. Штатно прошивка по USB-JTAG, так что это путь восстановления.

**Boot-уровни на ресете** (сэмплируются только на ресете, потом свободны): GPIO28 высокий = нормальная загрузка (pull-up). **GPIO27 обязан быть высоким** для валидного download, поэтому его линия WS2812 получает pull-up (`GPIO27=0` при `GPIO28=0` — невалидно). GPIO2 выбирает частоту кварца — boot-подтяжку под модуль (40 МГц = низкий). Уровень GPIO26 — сверить. Все strap-совмещённые сигналы гнать только после ресета.

## Ключевые цепи

```
SPI      : SCK(23) · MOSI(24) · MISO(6) → microSD, CC1101, 3× nRF24, SX1262, ST7796  (CS через U11)
LCD      : SPI + LCD_CS(U11.Y6) + LCD_DC(12) + LCD_RESX(PCA9555.P0.6) ; enable драйвера подсветки = PCA9555.P1.4
I2C      : SDA(0) · SCL(1) → Si4732, u-blox GPS(0x42), PCA9555(0x20), BQ25887 ; Grove-юниты (напр. RFID2 0x28) втыкаются
UART     : TX(11) → SA868.RX ; RX(15) ← SA868.TX
138      : A(2) B(3) C(25) → U11 ; G1=+3V3, G2B=GND, G2A=HC138_EN(PCA9555.P1.6, boot=высокий/выключен)
ENC      : A(4) B(5) с подтяжкой ; SW → PCA9555.P0.0
IR       : RX(10, RMT) ; TX(7, RMT/LEDC)
WS2812   : DIN(27, RMT) → сдвигатель на 5 В → DS1 ; держим тускло
RESET    : EN → RC (10k pull-up + 1µF) + SW_RST на GND
BOOT     : GPIO28 (внутр+внешн pull-up) → SW_BOOT на GND ; pull-up GPIO27 держит download валидным
USB      : D−(13) D+(14) → пара данных CC-стороны J1 ; ESD-массив
```

## Гочи

- **Strapping-пины намеренно несут выходы.** GPIO2/3/7/25/26/27 сэмплируются только на reset, потом свободны. На каждый — рекомендованная даташитом подтяжка; нагрузка не должна бороться с ней в t=0.
- **74HC138 выключен всё boot-окно.** `G2A` держится высоко (выключен) подтяжкой, пока прошивка не поднимет PCA9555 и не опустит `HC138_EN` — на strap-окне ни один CS не активен.
- **Прошивка по USB** (GPIO13/14). Это освобождает ноги UART0-консоли (GPIO11/12) под UART рации и `LCD_DC`. Оставить USB-пятачки; OTA — полевой путь.
- **PCA9555 — не для тайминга.** Всё с граничным таймингом (`GDO0`, `BUSY`, IR, WS2812, энкодер A/B) — только на прямой GPIO; расширитель везёт лишь сбросы, enable, PTT, мукс и кнопки. T/R LoRa полудуплексный, переключается по пакету — задержки I²C хватает.
- **I²C на GPIO0/1:** внешние подтяжки держат их высокими на boot (нормальный уровень); держать умеренными (4.7 кОм) и сверить boot-поведение GPIO0 на C5 до фиксации.
