# Leshy2 — лист C5 + шины (Лист 2)

*Читать на: [English](c5-buses.md) · **Русский***

ESP32-C5 и как от него расходятся все шины: общая SPI с дешифратором chip-select **74HC138**, I²C (с расширителем медленных сигналов **PCA9555**), UART к SA868, линии `DC`/`CS` дисплея, поворотный энкодер, USB и цепь reset/boot. Схема — в [c5-buses-schematic.svg](c5-buses-schematic.svg), логика ног — в [../../docs/pin-budget.md](../../docs/pin-budget.ru.md).

> ⚠️ Стадия проектирования. **Номера GPIO ниже — предлагаемая карта**, ещё не сверенная с даташитом ESP32-C5. До захвата схемы подтвердить: boot-уровни strapping-пинов (добавить рекомендованные даташитом подтяжки), какие ноги дотягиваются до RMT/FSPI/I²C, и переиспользование USB/UART-консоли. Функции зафиксированы, точные номера могут сдвинуться.

## MCU

**U10 — ESP32-C5-WROOM-1-N8R4** (или -N16R8): одно ядро RISC-V, нативный Wi-Fi 2.4 **и** 5 ГГц + BLE + 802.15.4, **8/16 МБ flash + 4/8 МБ PSRAM в корпусе**. PSRAM держит фреймбуфер дисплея 320×480×2 ≈ 300 КБ и рабочий набор порта прошивки. Внутрикорпусной flash/PSRAM занимает GPIO16–22 (не выведены). Нативный USB — на GPIO13/14.

## Карта GPIO (предлагаемая)

~20 рабочих GPIO (GPIO0–28 минус flash/PSRAM 16–22 минус USB 13/14). Прямых сигнальных ног — **19**; **GPIO28 = кнопка BOOT**, **EN = кнопка RESET**, кнопка включения — на PMIC (Лист 1).

| C5 GPIO | Цепь | Напр. | Периферия / примечание |

## Блоки и компоненты

| Ref | Компонент | Роль | Ключевое |
|-----|------|------|-----------|
| U10 | **ESP32-C5-WROOM-1** (PSRAM) | Мозг + мастер всех шин радио | `+3V3`; цепь EN + boot; USB на 13/14 |
| U11 | **74HC138** | Дешифратор chip-select 3→8 | `A/B/C` = GPIO2/3/25; `G1`=+3V3, `G2A/G2B`=GND (всегда включён); адресуя запасной выход, снимаем все CS |
| U12 | **PCA9555** | I²C-расширитель под медленные линии | I²C `0x20`; `INT` опционально (или опрос); везёт ~10 низкоскоростных сигналов |
| SW10 | Энкодер + нажатие | Навигация | `A/B` = GPIO4/5 (прямо); `SW` = PCA9555 |
| J10 | Отвод USB-C данных | Прошивка + данные + консоль | `D−/D+` = GPIO13/14; общий разъём J1 с листом питания |
| — | Развязка | Рейлы C5 | 10 мкФ + 0.1 мкФ на каждый `+3V3`; 1 мкФ на EN |

### 74HC138 — карта chip-select

| Выход | Chip-select | На листе SPI |
|:--:|------|------|
| Y0 | `SD_CS` | microSD |
| Y1 | `CC1101_CS` | sub-GHz |
| Y2 | `nRF24_1_CSN` | 2.4 raw #1 |
| Y3 | `nRF24_2_CSN` | 2.4 raw #2 |
| Y4 | `nRF24_3_CSN` | 2.4 raw #3 |
| Y5 | `LoRa_NSS` | SX1262 |
| Y6 | `LCD_CS` | дисплей ST7796 |
| Y7 | (никто) | **idle / адрес «снять все CS»** |

В каждый момент низкий только один Y, поэтому выбран лишь один прибор — естественно ложится на «одно радио за раз». Чтобы не говорить ни с кем (шина в покое), прошивка ставит `A/B/C` на **Y7**, который никуда не подключён.

### PCA9555 — карта медленных сигналов (I²C, 0 ног хоста)

| Порт | Сигнал | Напр. | Куда |
|:--:|------|:--:|------|
| P0.0 | `ENC_SW` | вх | нажатие энкодера |
| P0.1 | `SA868_PTT` | вых | push-to-talk рации |
| P0.2 | `SA868_PD` | вых | power-down рации |
| P0.3 | `Si4732_RST` | вых | сброс HF-приёмника |
| P0.4 | `LoRa_NRESET` | вых | сброс SX1262 |
| P0.5 | `BUZZER` | вых | сигнал (вкл/выкл или медленный тон) |
| P0.6 | `nRF24_IRQ` | вх | (или опрос по SPI) |
| P1.0 | `BQ_INT` | вх | прерывание зарядника (лист питания) |
| P1.1 | `BQ_CE` | вых | enable зарядника |
| P1.2 | `BQ_QON` | вых | выход из ship-mode |

Заряд батареи читается из **собственного I²C-ADC у BQ25887**, поэтому отдельная ADC-нога не нужна.

### Кнопки reset, boot и включения

Три физические кнопки, ни одной не нужен обычный GPIO:

- **RESET (SW_RST)** — момент. между **EN**–GND. На EN — RC сброса по питанию (10 кОм на `+3V3` + 1 мкФ на GND).
- **BOOT (SW_BOOT)** — момент. с **GPIO28** на GND. GPIO28 — strap загрузки C5 (низкий на ресете → serial bootloader) с внутренней подтяжкой; добавить и внешнюю. Держать BOOT + тапнуть RESET = принудительный download. Штатно прошивка по USB-JTAG, так что это путь восстановления.
- **POWER (SW_PWR)** — на пин **`/QON` BQ25887** (выход из ship-mode), на листе питания — работает при полностью выключенном MCU. Нажать = включить; выключение — команда ship-mode по I²C.

**Boot-уровни на ресете** (сэмплируются только на ресете, потом свободны): GPIO28 высокий = нормальная загрузка (pull-up). **GPIO27 обязан быть высоким** для валидного download, поэтому его линия WS2812 получает pull-up (`GPIO27=0` при `GPIO28=0` — невалидно). GPIO2 выбирает частоту кварца — boot-подтяжку под модуль (40 МГц = низкий). Уровень GPIO26 — сверить. Все strap-совмещённые сигналы гнать только после ресета.

## Ключевые цепи

```
SPI      : SCK(23) · MOSI(24) · MISO(6) → microSD, CC1101, 3× nRF24, SX1262, ST7796  (CS через U11)
LCD      : SPI + LCD_CS(U11.Y6) + LCD_DC(12) ; подсветка через PCA9555 или +3V3
I2C      : SDA(0) · SCL(1) → Si4732, u-blox GPS(0x42), RFID2(0x28), PCA9555(0x20), BQ25887, Grove
UART     : TX(11) → SA868.RX ; RX(15) ← SA868.TX
138      : A(2) B(3) C(25) → U11 ; G1=+3V3, G2A=G2B=GND
ENC      : A(4) B(5) с подтяжкой ; SW → PCA9555.P0.0
IR       : RX(10, RMT) ; TX(7, RMT/LEDC)
WS2812   : DIN(27, RMT) ; +5V ; держим тускло
RESET    : EN → RC (10k pull-up + 1µF) + SW_RST на GND
BOOT     : GPIO28 (внутр+внешн pull-up) → SW_BOOT на GND ; pull-up GPIO27 держит download валидным
POWER    : SW_PWR → BQ25887 /QON (выход из ship-mode, лист питания)
USB      : D−(13) D+(14) → пара данных CC-стороны J1 ; ESD-массив
```

## Гочи

- **Strapping-пины намеренно несут выходы.** GPIO2/3/7/25/26/27 сэмплируются только на reset, потом свободны. На каждый — рекомендованная даташитом подтяжка, чтобы плата всегда стартовала в нормальном boot; нагрузка не должна бороться с подтяжкой в t=0 (здесь все — выходы или Hi-Z входы).
- **Прошивка по USB** (GPIO13/14). Это освобождает ноги UART0-консоли (GPIO11/12) под UART рации и `LCD_DC`. Оставить USB-пятачки; OTA — полевой путь.
- **Один CS за раз.** 74HC138 физически не может выбрать два прибора сразу — хорошо для изоляции, но прошивка обязана ставить адрес на **Y7** перед сменой радио.
- **PCA9555 — не для тайминга.** Всё с граничным таймингом (`GDO0`, `BUSY`, IR, WS2812, энкодер A/B) — только на прямой GPIO; расширитель везёт лишь сбросы, enable, PTT и кнопки.
- **I²C на GPIO0/1:** внешние подтяжки держат их высокими на boot (нормальный уровень), но подтяжки умеренные (4.7 кОм), и boot-поведение GPIO0 на C5 сверить до фиксации.
