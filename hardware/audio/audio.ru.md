# Leshy2 — Лист «Аудио» (Лист 4)

*Читать на: [English](audio.md) · **Русский***

Две аудио-рации и полностью аналоговый тракт до динамика: **Si4732** (приёмник HF / CB / FM, I²C) и **SA868-U** (голосовая UHF-рация, UART). Их аналоговые линейные выходы идут через **аналоговый мукс 2:1** на класс-D усилитель **PAM8302**; электретный микрофон кормит передачу SA868. МК **не** в аудио-тракте — ЦАПа нет. Всё висит на мозге **ESP32-S3**: управление — на двух расширителях **PCA9555**, данные — на **UART1 SA868** и **I²C Si4732**. Это две из девяти антенн на плате.

> ⚠️ Стадия проектирования. Аналоговые уровни, суммирующие резисторы и смещение микрофона — стартовые значения под проверку на живом железе. Si4732 и весь аналоговый фронтенд питаются от тихого рейла LDO **`+3V3A`** (от `+5V`, см. [лист питания](../power/power.ru.md)); УМ SA868 — от **`+5V`**.

## Блоки и элементы

| Ref | Часть | Роль | Ключевое |
|-----|-------|------|----------|
| U30 | **Si4732-A10** | Приёмник AM/SSB/CW + FM: CB 27 МГц, весь HF/SW, MW/LW, FM 64–108 | **только A10** — SSB-патч на A11 не встанет; I²C `0x11`, телескоп |
| U31 | **SA868-U** | Голос UHF NBFM, RX + TX ≤ 2 Вт | UART1 + PTT + PD; своя SMA |
| U32 | **PAM8302A** | Моно класс-D, ~2.5 Вт @ 4 Ом | выход BTL; SD (shutdown) на PCA #1 |
| U33 | **74LVC1G3157** | Аналоговый мукс 2:1 — выбирает живой источник в УМ | одна линия выбора, PCA #1 |
| MK1 | Электрет + смещение | Передающий звук SA868 | аналог → SA868 MIC через **1 мкФ** |
| LS1 | Динамик 4–8 Ом | Выход | от PAM8302 (BTL, плавающий) |
| J30 | Гнездо 3.5 мм | Отвод на наушники + мех. мьют при вставке | jack-detect на PCA #2 (см. грабли) |

Громкость задаётся **внутри каждой рации** — Si4732 регистром по I²C, SA868 командой по UART — так что аналогового потенциометра нет; усиление PAM8302 фиксировано резисторами.

## Ключевые цепи

```
Si4732 (U30)  — аналоговый фронтенд, всё на +3V3A
  I2C     : SDA=GPIO4 · SCL=GPIO5   адрес 0x11 (SEN → GND)
  reset   : RST  → PCA #1 (0x20) P0.3
  clock   : RCLK ← ВЫДЕЛЕННЫЙ осц. 32.768 кГц (НЕ от МК) + грузовые кап.
  антенна : телескоп HF/CB → AMI через матч + ESD-кламп (встречно-парал. диоды)
            отвод FM → FMI (последоват. кап)
  звук    : LOUT + ROUT → пара суммирующих R (L+R → моно) → мукс U33.A

SA868-U (U31)
  UART1   : TX=GPIO16 → U31.RXD · RX=GPIO17 ← U31.TXD
  управл. : PTT → PCA #1 P0.1 · PD → PCA #1 P0.2
  питание : VBAT = +5V + локальный bulk 220–470 мкФ + 100 нФ (всплеск УМ 2 Вт)   ; модуль с одним питанием
  антенна : UHF → SMA
  RX звук : U31.AF_OUT → мукс U33.B
  TX звук : MK1 электрет → 1 мкФ → U31.MIC_IN   (см. грабли)

Аудио-выход
  мукс    : выбор U33 = MUX_SEL → PCA #1 P0.7  (Si4732 или SA868, живёт один)
  УМ      : U33.OUT → R_in → PAM8302.IN ; SD = PAM_SD → PCA #1 P1.3 ; Vcc = +5V
  динамик : PAM8302 OUT± → LS1 (4–8 Ом, BTL, без опоры на землю)
  гнездо  : J30 JACK_DET → PCA #2 (0x21) P0.3 ; AC-развязка обоих плеч (см. грабли)
```

## Аналоговая маршрутизация — по одному источнику

Режим рации взаимоисключающий, поэтому живёт всегда только один источник звука. Маленький **аналоговый ключ 2:1 (U33, 74LVC1G3157)** чисто заводит в УМ либо линейный выход Si4732, либо RX-звук SA868 — без артефактов смешивания, а простаивающий источник полностью изолирован. Всё делает одна линия управления (`MUX_SEL`, PCA #1 P0.7).

## Si4732 — приёмный фронтенд

- **Ревизия A10, не A11.** Загружаемый **SSB-патч встаёт только на A10**; кристалл A11 будет играть FM/AM, но молча откажет в SSB/CW. Заказывать и маркировать A10.
- **Чистое питание:** малошумящий LDO **`+3V3A`** держит коммутационный шум подальше от приёмника.
- **RCLK от выделенного осциллятора 32.768 кГц**, не от МК — отдельный часовой кристалл/осциллятор со своими грузовыми кап. Общий клок с МК занёс бы в тюнер цифровой джиттер. Дорожки короткие, иначе может не стартовать.
- **Адрес I²C:** **SEN → GND** даёт `0x11` (SEN → VIO = 0x63); зафиксировать, чтобы адрес был детерминирован.
- **Защита ВЧ-входа:** телескоп кормит `AMI` через матчинг с **пассивным ESD-клампом (встречно-параллельные диоды)**. Отвод FM кормит `FMI` через **последовательный кап**. **Ручного отключения антенны нет** — от де-сенса собственными передатчиками спасает режимно-исключающий сон, а телескоп откручивается.
- **Линейный выход:** `LOUT`/`ROUT` — настоящий аналоговый звук; **пара суммирующих резисторов** сводит L+R в моно на единственный динамик.

## SA868-U — голосовая рация

- **Управление по UART1** (частота, шумодав, громкость); **PTT** ключует TX, **PD** усыпляет модуль. Обе линии медленные → на **PCA #1** (P0.1 / P0.2).
- **Одно питание `VBAT` на `+5V`** ради всплеска 2 Вт; локальный **bulk (220–470 мкФ + 100 нФ у VBAT модуля)**, чтобы всплеск PTT не просаживал рейл и не искажал TX. Рейл +5V рассчитан на это (лист питания).
- **Легальная мощность** режется по региону в прошивке (446 PMR ≤ 0.5 Вт ERP; 5 Вт — только на любительских 70 см с лицензией).

## PAM8302 — усилитель динамика

- Несимметричный вход с мукса, усиление задано входным резистором; **SD** (shutdown, PCA #1 P1.3) глушит УМ и экономит питание между звуками.
- **Выход BTL** качает динамик напрямую — **не** заземлять ни один вывод динамика.

## Фаб-реализация (реальные детали)

`hardware/tscircuit/audio.tsx` — фаб-черновик: реальные футпринты/распиновки тянутся движком
из LCSC. DRC KiCad = **0 неподключённых / 0 замыканий / 0 расхождений**.

| Ref | Деталь | LCSC |
|-----|------|------|
| U30 | Si4732-A10-GS (16-SOIC) | C1526102 |
| U31 | модуль рации SA868-U | C3001507 |
| U32 | PAM8302AASCR (8-pin MSOP) | C113367 |
| U33 | мукс SN74LVC1G3157 | C10426 |
| Y1 | кварц 32.768 кГц NX3215SA | C280830 |

Правки, найденные при реализации на реальных деталях:
- **SA868-U — с одним питанием.** У реального модуля один вывод **`VBAT`** (3.3–5.5 В), а не
  раздельные `VIN`+`VCC3V3`, как предполагала база — `VBAT` → `+5V`, 3В3-вывод убран. Внутренний
  УНЧ модуля включается `AudioON` (активный-низкий) → на GND.
- **PAM8302A — корпус 8-pin MSOP**, а не SOT-23-6.
- Si4732 получил `RFGND` → GND и ВЧ-декап 100 нФ на VDD.

Подтвердить при разводке: **`H/L` (нога 7) SA868 оставлен open = 2 Вт (high)** — притянуть к
низкому (или завести линию управления) для регионов с лимитом ≤0.5 Вт (установка мощности по
UART тоже доступна); ноги Si4732 1/2/3/16 (движок без имён → ROUT/LOUT/NC); джек 3.5 мм и
микрофон/динамик — плейсхолдеры; нагрузочные ёмкости кварца (12 пФ) — под конкретный кварц.

## Грабли

- **Гнезду наушников нужна AC-развязка — усилитель BTL.** У PAM8302 нет опоры на землю; оба выхода качаются. Обычное гнездо TRS сажает `sleeve → GND`, что **закоротит одно плечо моста** и убьёт/перегреет УМ. Ставить **разделительные кап на оба плеча** (или отдельный несимметричный драйвер наушников) перед J30; механический мьют при вставке — норм. `JACK_DET` на **PCA #2 P0.3**.
- **Si4732 обязан быть A10.** Кристалл A11 выглядит идентично и работает на FM/AM, поэтому дефект вылезает, только когда SSB молчит. Плата с не той ревизией софтом не чинится.
- **Разделительный кап микрофона = 1 мкФ, не 10 мкФ.** 10 мкФ в MIC SA868 образует долгую RC со схемой смещения, из-за чего первые ~0.5 с звука передачи нарастают и **первое слово срезается**. 1 мкФ устаканивается быстро.
- **У МК нет ЦАПа.** Весь звук — аналоговый линейный выход → мукс → УМ; баззер (лист управления) — единственный звук от МК.
- **Держать +3V3A тихим.** Разводить питание Si4732 / аудио-SA868 подальше от бустов и возвратов УМ nRF24; шумный аналоговый рейл вылезает шипением в приёмнике. Учесть интерлок: `+3V3A` кормится от `+5V`, поэтому снятие рейла +5V заодно глушит и HF-приём.
- **Мьют перед переключением.** Поднимать `SD` PAM8302 на время перекидки мукса между источниками, чтобы не щёлкало.
