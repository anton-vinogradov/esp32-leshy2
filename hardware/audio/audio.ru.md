# Leshy2 — лист аудио (Лист 4)

*Читать на: [English](audio.md) · **Русский***

Два звуковых радио и полностью аналоговый тракт до динамика: **Si4732** (приёмник HF / CB / FM, I²C) и **SA868-U** (голосовая рация 433 / 446 МГц, UART), их аналоговые line-out сведены в усилитель класса D **PAM8302**, плюс электретный микрофон для передачи рации. MCU **не** в аудиотракте — ЦАП нет. Управляющие ноги — с [Листа 2](../c5-buses/c5-buses.ru.md); это последние две из восьми бортовых антенн.

> ⚠️ Стадия проектирования. Аналоговые уровни, суммирующие резисторы и смещение микрофона — стартовые точки для проверки на железе. Оба радио — на тихом аналоговом рейле **`+3V3A`** с листа питания; PA рации — на **`+5V`**.

## Блоки и компоненты

| Ref | Компонент | Роль | Интерфейс |
|-----|------|------|-----------|
| U30 | **Si4732-A10** | Приёмник AM/SSB/CW + FM: CB 27 МГц, весь HF/SW, MW/LW, FM 64–108 | I²C + RST + RCLK 32.768 кГц + аналог LOUT/ROUT |
| U31 | **SA868-U** | Голос NBFM 433/446, RX + TX ≤ 2 Вт | UART + PTT + PD + AF-out + MIC-in |
| U32 | **PAM8302A** | Моно усилитель класса D, ~2.5 Вт @ 4 Ω | аналог IN + SD (shutdown) |
| U33 | Аналоговый мукс 2:1 (74LVC1G3157) | выбирает активный источник в усилитель | 1 линия выбора (PCA9555) |
| MK1 | Электретный микрофон + смещение | Звук передачи рации | аналог → SA868 MIC |
| LS1 | Динамик 4–8 Ω | Выход | от PAM8302 (BTL) |
| J30 (опц.) | Гнездо 3.5 мм | Отвод на наушники + мьют динамика при вставке | jack-detect → PCA9555 |

Громкость задаётся **внутри каждого радио** — Si4732 регистром по I²C, SA868 командой по UART — поэтому аналогового потенциометра громкости нет; усиление PAM8302 фиксировано резисторами.

## Цепи

```
Si4732 (U30)
  I2C     : SDA(0) · SCL(1)                         RST → PCA9555.P0.3
  clock   : кварц 32.768 кГц на RCLK/GPO3 + 2×~22 пФ load-капы   VDD → +3V3A ; SEN → GND (адрес 0x11)
  антенна : HF/CB телескоп → AMI через матч + ESD-кламп ; FM-отвод → FMI (последоват. кап)
  audio   : LOUT + ROUT → (сумма L+R) → мукс U33.A

SA868-U (U31)
  UART    : TX(11) → U31.RXD · RX(15) ← U31.TXD     PTT → PCA9555.P0.1 · PD → PCA9555.P0.2
  power   : Vin модуля = +5V + локальный bulk 220–470µF + 100nF (бросок PA 2 Вт) ; логика 3V3
  антенна : 433/446 UHF → SMA
  RX audio: U31.AF_OUT → мукс U33.B
  TX audio: MK1 электрет → 1 мкФ → U31.MIC_IN       (см. гочу)

Выход аудио
  мукс    : выбор U33 = PCA9555.P0.7 (Si4732 либо SA868, один активен за раз)
  усил.   : U33.OUT → R_in → PAM8302.IN+ ; MUX_SEL → PCA9555.P0.7 ; PAM_SD → PCA9555.P1.3 ; +5V
  динамик : PAM8302 OUT± → LS1 (4–8 Ω, BTL, без опоры на землю)
  опц гнездо: J30 tip = отвод линии до усил. ; switch гильзы → мьют PAM8302
```

## Аналоговая коммутация — один источник за раз

Так как радиорежим эксклюзивен, живой звуковой источник всегда один, поэтому крошечный **аналоговый свитч 2:1 (U33)** чисто заводит либо line-out Si4732, либо RX-звук SA868 в усилитель — без артефактов смешивания, а простаивающий источник полностью изолирован. (Пассивное резисторное суммирование тоже сработает, если простаивающий источник заглушить по I²C/UART, но свитч чище при одной управляющей линии.)

## Si4732 — приёмный фронтенд

- **Чистое питание:** `+3V3A` (малошумящий LDO, лист питания) держит шум переключений подальше от приёмника.
- **RCLK:** опорой служит часовой кварц 32.768 кГц — добавить **два ~22 пФ load-капа** (под CL кварца), иначе может не стартовать; трассы короткими.
- **I²C-адрес:** притянуть **SEN → GND** для адреса `0x11` (SEN → VIO = 0x63); зафиксировать, чтобы адрес был детерминирован.
- **Защита HF-входа:** большой телескоп заводит `AMI` через матчинг с **пассивным ESD/кламп** (встречно-параллельные диоды). **Ручного отключения антенны нет** — де-сенс от собственных передатчиков решён режимным сном, а телескоп откручивается.
- **Line-out:** `LOUT`/`ROUT` — реальный аналог; сумма L+R в моно на единственный динамик.

## SA868-U — голосовая рация

- **Управление по UART** (частота, шумодав, громкость); **PTT** ключует TX, **PD** усыпляет модуль. Оба медленные → на PCA9555.
- **PA на `+5V`** под бросок 2 Вт; добавить **локальный bulk (220–470 мкФ + 100 нФ у Vin модуля)**, чтобы бросок PTT не просаживал рейл и не искажал TX. Рейл +5V под это рассчитан (лист питания).
- **Легальная мощность** ограничена по региону в прошивке (446 PMR ≤ 0.5 Вт ERP; 5 Вт только на любительском 70 см с лицензией).

## PAM8302 — усилитель динамика

- Несимметричный вход от мукса, усиление задано входным резистором; **SD** (shutdown) на PCA9555 глушит усилитель и экономит питание между звуками.
- **BTL-выход** качает динамик напрямую — **не** заземлять ни один вывод динамика.

## Гочи

- **Кап связи микрофона = 1 мкФ, не 10 мкФ.** 10 мкФ на вход MIC SA868 образует долгую RC со смещением, поэтому первые ~0.5 с звука передачи нарастают и первое слово срезается. 1 мкФ устаканивается быстро.
- **У MCU нет ЦАП.** Весь звук — аналоговый line-out → усилитель; любой тон от MCU был бы только I²S-кодеком, намеренно вне приёмного тракта. Buzzer (Лист 2) — единственный звук от MCU.
- **Держи +3V3A тихим.** Питание аудио Si4732/SA868 разводить в стороне от бэков и возвратов PA nRF24; шумный аналоговый рейл слышен как шипение приёмника.
- **Мьют перед переключением.** Ставить PAM8302 `SD`, пока мукс перекидывает источники, чтобы не щёлкало.
