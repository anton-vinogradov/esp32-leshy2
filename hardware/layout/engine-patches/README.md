# Experimental engine patches / экспериментальные исправления

`krt-0.22.0-npth-via-floor.patch` targets [KiCadRoutingTools](https://github.com/drandyhaas/KiCadRoutingTools) commit `5a7fbcb6ee4deebd1d9ec1d5bd094d8681f502f3`. Its SHA256 is `f23c065706e02fd003d350f9cd4c308de7b5849981d98a023c10d43850884b03`. Upstream code is MIT-licensed; its notice is retained alongside this patch.

The patch consistently applies the declared copper-to-NPTH floor to via obstacles, post-route nudging and internal DRC. It includes seven regression tests, including the actual failing RF/UI coordinates. It does not weaken rules or change the Rust binary. Apply only to an isolated checkout with `git apply`; never mutate the pinned baseline while a comparison is running. Independent native KiCad validation remains mandatory. Passing unit tests alone is not routing or production acceptance.

Патч согласованно учитывает заданный зазор от меди до NPTH в препятствиях для via, последующем сдвиге via и внутреннем DRC. Семь тестов включают реальные ошибочные координаты RF/UI. Правила и Rust-бинарник не меняются. Применять через `git apply` только в отдельной копии указанной версии; исходный движок во время сравнения не менять. Независимая проверка KiCad обязательна; одних unit-тестов недостаточно для принятия трассировки или производства.

## Pending-pad experiment / эксперимент защиты площадок

`krt-0.22.0-npth-pending-pad.patch` is a **combined replacement**, not a patch to apply on top of the first one. Apply it to the same clean upstream commit. SHA256: `0dec1ef898beec101580f496a7ef48a9042cb45ad77b29b2468e26c3f8a63067`. It retains the NPTH fix and adds opt-in `KICAD_PENDING_PAD_PROTECTION=1`: existing soft approach costs can persist for unescaped pads after a multipoint net's first branch is routed. It creates no copper and changes no clearance rules. Nine additional tests cover default-off behavior, owner exclusion, attachment/rip lifecycle and all four obstacle builders. Retirement reuses the engine's XY attachment heuristic, **not electrical connectivity**; strict native validation remains authoritative. Unit-test success does not establish a successful 474-connection campaign.

`krt-0.22.0-npth-pending-pad.patch` — **совмещённая замена**, не дополнение поверх первого патча; применять к той же чистой upstream-версии. Он сохраняет исправление NPTH и добавляет выключенную по умолчанию опцию `KICAD_PENDING_PAD_PROTECTION=1`: мягкая защита подходов к площадкам может сохраняться после трассировки первой ветви многоточечной сети. Медь не создаётся, правила зазоров не меняются. Девять новых тестов проверяют выключенное состояние, исключение собственной сети, появление/удаление подходящей меди и четыре пути построения препятствий. Снятие защиты использует существующую XY-эвристику, **не проверку электрической связности**; окончательное решение остаётся за независимым native-контролем. Успех unit-тестов не означает прохождения бенчмарка 474 связей.
