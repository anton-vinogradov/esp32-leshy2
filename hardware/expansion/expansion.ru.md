# Leshy2 — лист расширения + GPS (Лист 5)

*Читать на: [English](expansion.md) · **Русский***

Два куска «всего остального»: бортовой **u-blox GPS** на своём **UART** и **шина I²C** с её **картой адресов** плюс **два Grove I²C-порта** под втыкаемые M5/Grove-юниты (RFID2 NFC, сенсоры). Всё висит на **S3** (главный мозг). GPS сидит на UART намеренно — так поток NMEA не грузит I²C, и общая шина остаётся лёгкой. Два расширителя **PCA9555** едут на этой же шине I²C (нарисованы на [Листе 2](../c5-buses/c5-buses.ru.md)); Si4732 — на [Листе 4](../audio/audio.ru.md), зарядник BQ25887 — на [Листе 1](../power/power.ru.md).

> ⚠️ Стадия проектирования. Одна пара подтяжек на всю шину I²C, сигналы `+3V3`, питание Grove по умолчанию `+3V3`. Сверить адрес каждого юнита до фиксации; коллизии решаются муксом, а не лишними ногами.

## Блоки и компоненты

| Ref | Компонент | Роль | Интерфейс |
|-----|------|------|-----------|
| U40 | **u-blox SAM-M8Q** (онборд) | GNSS со **своей патч-антенной**; позиция + время для Meshtastic | **UART** (NMEA) |
| BT40 | Суперкап + Шоттки | резерв GPS (hot-start) на `V_BCKP` от `+3V3` | V_BCKP |
| J40 / J41 | **Grove HY2.0-4P** (I²C) ×2 | два втыкаемых порта под M5 I²C-юниты | `+3V3` · GND · SDA · SCL (5 В через джампер) |
| U41 (опц.) | Grove I²C-хаб (пассивный) | развести несколько юнитов на один порт | I²C |
| U42 (опц.) | Мукс **TCA9548A** | только если два юнита делят адрес | I²C `0x70` |
| — | RFID2 Unit (WS1850S) | пример M5-юнита: NFC 13.56 МГц | Grove I²C `0x28` |
| R40/R41 | 4.7 кОм ×2 | единые подтяжки шины (SDA/SCL к `+3V3`) | — |
| D40/D41 | ESD-массив ×2 | защита каждого Grove-разъёма | — |
| U43 (опц.) | PCA9306 / TCA9517 | I²C-транслятор уровней для 5 В Grove-юнита | I²C |

## Ключевые цепи

```
GPS (U40, онборд)
  UART2   : S3 GPIO18 ← U40.TXD (GPS_UART_RX, NMEA, обязателен)
            S3 GPIO47 → U40.RXD (GPS_UART_TX, опц., только конфиг)
  питание : VCC = +3V3 ; V_BCKP ← суперкап + Шоттки (BT40) для hot-start
  антенна : своя GNSS патч-антенна (встроена в SAM-M8Q)
  1PPS    : timepulse не подключён (нет свободной ноги; времени из NMEA хватает)

Шина I²C (общая, хост S3)
  линии   : SDA = GPIO4 · SCL = GPIO5 ; одна пара подтяжек 4.7 кОм → +3V3 (R40/R41)
  онборд  : Si4732 0x11 · PCA9555 #1 0x20 · PCA9555 #2 0x21 · BQ25887 0x6A
  Grove   : J40 + J41 → SDA/SCL/GND/+3V3 + ESD (D40/D41)
  опц     : TCA9548A 0x70 только под коллизии адресов ; PCA9306 под 5 В юнит
```

## Карта адресов I²C

| Адрес | Прибор | Лист |
|:--:|------|:--:|
| `0x11` | Приёмник Si4732 (SEN = GND) | 4 |
| `0x20` | Расширитель PCA9555 #1 | 2 |
| `0x21` | Расширитель PCA9555 #2 | 2 |
| `0x28` | RFID2 NFC (Grove) | 5 |
| `0x6A` | Зарядник BQ25887 | 1 |
| `0x70` | Мукс TCA9548A (если нужен) | 5 |
| — | прочие Grove-юниты | втыкаемые |

Все делят SDA (GPIO4) / SCL (GPIO5) с **одной** парой подтяжек 4.7 кОм на всю шину — не по подтяжке на прибор. **GPS здесь нет** — он ушёл на UART, что снимает с шины постоянный трафик NMEA.

## u-blox GPS — на плате, по UART

**SAM-M8Q** несёт **свою патч-антенну**, поэтому паяется прямо на плату и требует лишь `+3V3`, одну линию UART на вход, опциональную на выход и **резервное питание** (суперкап + Шоттки от `+3V3`) на `V_BCKP`, чтобы эфемериды пережили провал питания ради быстрого hot-start. Он **сам шлёт NMEA** сразу после включения — S3 достаточно читать `GPS_UART_RX` (GPIO18); обратная линия `GPS_UART_TX` (GPIO47) опциональна, нужна лишь для конфигурации (частота фикса, набор сообщений). Работа по **UART2, а не I²C** намеренно уводит непрерывный поток NMEA с общей шины I²C. Timepulse 1 PPS не подключён (нет свободной ноги; времени из NMEA хватает). На плате — значит позиция всегда есть, а оба Grove-порта свободны под другие юниты.

## Grove I²C-порты — два сокета расширения

**Два** одинаковых разъёма **Grove HY2.0-4P** (J40, J41) выводят каждый **`+3V3`**, GND и пару I²C с ESD-массивом — S3 не толерантен к 5 В, поэтому порты по умолчанию 3.3 В (большинство M5/Grove I²C-юнитов работают от 3.3 В). Питание `+5V` — отдельная опция джампером и только за двунаправленным I²C-транслятором (PCA9306 / TCA9517, U43), чтобы 5-вольтовый юнит не мог задрать SDA/SCL выше 3.3 В. Оба порта сидят на **одной** шине I²C — второй это удобный сокет, а не вторая шина, так что лишних GPIO он не стоит. Принимают M5 **I²C**-юниты — RFID2 NFC, RTC, IMU/компас, сенсоры окружения — каждый по своему адресу. Чтобы воткнуть несколько на один разъём, пассивный **Grove I²C-хаб** (U41) его разводит; и только если два юнита совпадают по адресу, нужен мукс **TCA9548A** (U42).

## Гочи

- **По умолчанию порты 3.3 В.** SDA/SCL — `+3V3` (S3 не толерантен к 5 В). Питание Grove — `+3V3`; 5-вольтовому юниту нужен и джампер, **и** I²C-транслятор (U43), чтобы он не задрал линии выше 3.3 В.
- **Один комплект подтяжек на всю шину.** Оба Grove-порта и все бортовые приборы делят единственную пару R40/R41. Юнит со своими подтяжками SDA/SCL перегружает шину; брать юниты без подтяжек или учитывать параллельное сопротивление.
- **Коллизии адресов → мукс, не ноги.** Два юнита `0x28` (скажем, два RFID2) требуют TCA9548A; на вторую шину бюджета ног нет. **Каждый задействованный канал за TCA9548A требует своей пары подтяжек** — FET-ключи мукса изолируют каналы, и общие подтяжки шины до них не дотягиваются.
- **GPS хочет чистое небо и хороший резервный кап.** Без удержания `V_BCKP` каждый старт — холодный (30–60 с); суперкап + Шоттки дают hot-start через провал питания.
- **DAC-out Grove-юниты не работают** — у S3 нет ЦАП; ничто на Grove это не вернёт.
- **Горячая замена — осторожно.** Grove-порты не рассчитаны на hot-swap; выключать питание перед втыканием юнита или добавить последовательные резисторы на SDA/SCL.
