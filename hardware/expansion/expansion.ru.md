# Leshy2 — лист расширения (Лист 5)

*Читать на: [English](expansion.md) · **Русский***

Два куска «всего остального»: **порт Grove-UART под GPS** (S3 UART2, выведенный под внешний M5 GPS Unit) и **шина I²C** с её **картой адресов** плюс **два Grove I²C-порта** под втыкаемые M5/Grove-юниты (RFID2 NFC, сенсоры). Всё висит на **S3** (главный мозг). GPS сидит на UART намеренно — так поток NMEA не грузит I²C, и общая шина остаётся лёгкой. Три расширителя **PCA9555** едут на этой же шине I²C (нарисованы на [Листе 2](../c5-buses/c5-buses.ru.md)); Si4732 — на [Листе 4](../audio/audio.ru.md), зарядник BQ25887 — на [Листе 1](../power/power.ru.md).

> ♻️ **Бортовой GPS убран.** Ранние черновики паяли на плату u-blox **SAM-M8Q** (U40) со своей патч-антенной и резервным суперкапом (BT40). Этого **больше нет** — GPS теперь **внешний M5 GPS Unit** (UART), втыкаемый в порт **Grove-UART** и несущий свою антенну. Освободившийся у S3 **UART2** (GPIO18 = RX, GPIO47 = TX) выведен на этот Grove-UART-разъём. Оба I²C Grove-порта без изменений. Строки U40 / BT40 / развязки GPS ниже — **устаревшие**, оставлены для истории до тех пор, пока ре-нетлист двух плат не уберёт их из `.tsx`.

> ⚠️ Стадия проектирования. Одна пара подтяжек на всю шину I²C, сигналы `+3V3`, питание Grove по умолчанию `+3V3`. Сверить адрес каждого юнита до фиксации; коллизии решаются муксом, а не лишними ногами.

## Ключевые цепи

```
GPS (внешний M5 GPS Unit на порту Grove-UART J_GPS — бортовой U40 убран)
  UART2   : S3 GPIO18 ← J_GPS RX (GPS_UART_RX, NMEA, обязателен)
            S3 GPIO47 → J_GPS TX (GPS_UART_TX, опц., только конфиг)
  питание : Grove +3V3 · GND к M5 GPS Unit
  антенна : внешняя — своя антенна у M5 GPS Unit
  резерв  : внутри M5 GPS Unit (бортового суперкапа V_BCKP нет)

Шина I²C (общая, хост S3)
  линии   : SDA = GPIO4 · SCL = GPIO5 ; одна пара подтяжек 4.7 кОм → +3V3 (R40/R41)
  онборд  : Si4732 0x11 · PCA9555 #1 0x20 · PCA9555 #2 0x21 · PCA9555 #3 0x22 · touch ~0x38 · BQ25887 0x6A
  Grove   : J40 + J41 → SDA/SCL/GND/+3V3 + ESD (D40/D41)
  опц     : TCA9548A 0x70 только под коллизии адресов ; PCA9306 под 5 В юнит
```

## Карта адресов I²C

| Адрес | Прибор | Лист |
|:--:|------|:--:|
| `0x11` | Приёмник Si4732 (SEN = GND) | 4 |
| `0x20` | Расширитель PCA9555 #1 | 2 |
| `0x21` | Расширитель PCA9555 #2 | 2 |
| `0x22` | PCA9555 #3 (кнопки UI) | 2 |
| `0x28` | RFID2 NFC (Grove) | 5 |
| `0x6A` | Зарядник BQ25887 | 1 |
| `0x70` | Мукс TCA9548A (если нужен) | 5 |
| — | прочие Grove-юниты | втыкаемые |

Все делят SDA (GPIO4) / SCL (GPIO5) с **одной** парой подтяжек 4.7 кОм на всю шину — не по подтяжке на прибор. **GPS здесь нет** — он на отдельном порту Grove-UART (внешний M5 GPS Unit), что держит постоянный трафик NMEA вне этой шины.

## GPS — внешний M5 Unit на Grove-UART

GPS — **внешний M5 GPS Unit** (UART), втыкаемый в порт **Grove-UART** (`J_GPS`). У S3 на этот разъём выведен **UART2**: S3 читает `GPS_UART_RX` (GPIO18) — поток NMEA, который юнит **шлёт сам** после включения; обратная линия `GPS_UART_TX` (GPIO47) опциональна, нужна лишь для конфигурации (частота фикса, набор сообщений). Работа по **UART, а не I²C** намеренно уводит непрерывный поток NMEA с общей шины I²C. Юнит несёт **свою антенну** и свой резерв под hot-start, поэтому плате не нужны ни патч-антенна, ни резервный суперкап. Оба I²C Grove-порта остаются свободны под другие юниты.

> ♻️ **Устарело — бортовой GPS.** Ранние черновики ставили на плату **u-blox SAM-M8Q** (U40) со своей патч-антенной, резервным суперкапом + Шоттки (BT40) на `V_BCKP` и развязкой GPS по даташиту. Всё это **убрано**. Строки U40 / BT40 в таблицах выше и ниже остаются лишь до тех пор, пока ре-нетлист двух плат не уберёт их из `.tsx`.

## Grove I²C-порты — два сокета расширения

**Два** одинаковых разъёма **Grove HY2.0-4P** (J40, J41) выводят каждый **`+3V3`**, GND и пару I²C с ESD-массивом — S3 не толерантен к 5 В, поэтому порты по умолчанию 3.3 В (большинство M5/Grove I²C-юнитов работают от 3.3 В). Питание `+5V` — отдельная опция джампером и только за двунаправленным I²C-транслятором (PCA9306 / TCA9517, U43), чтобы 5-вольтовый юнит не мог задрать SDA/SCL выше 3.3 В. Оба порта сидят на **одной** шине I²C — второй это удобный сокет, а не вторая шина, так что лишних GPIO он не стоит. Принимают M5 **I²C**-юниты — RFID2 NFC, RTC, IMU/компас, сенсоры окружения — каждый по своему адресу. Чтобы воткнуть несколько на один разъём, пассивный **Grove I²C-хаб** (U41) его разводит; и только если два юнита совпадают по адресу, нужен мукс **TCA9548A** (U42).

## Гочи

- **По умолчанию порты 3.3 В.** SDA/SCL — `+3V3` (S3 не толерантен к 5 В). Питание Grove — `+3V3`; 5-вольтовому юниту нужен и джампер, **и** I²C-транслятор (U43), чтобы он не задрал линии выше 3.3 В.
- **Один комплект подтяжек на всю шину.** Оба Grove-порта и все бортовые приборы делят единственную пару R40/R41. Юнит со своими подтяжками SDA/SCL перегружает шину; брать юниты без подтяжек или учитывать параллельное сопротивление.
- **Коллизии адресов → мукс, не ноги.** Два юнита `0x28` (скажем, два RFID2) требуют TCA9548A; на вторую шину бюджета ног нет. **Каждый задействованный канал за TCA9548A требует своей пары подтяжек** — FET-ключи мукса изолируют каналы, и общие подтяжки шины до них не дотягиваются.
- **GPS теперь внешний.** M5 GPS Unit на порту Grove-UART несёт свою антенну и свой резерв, поэтому бортового суперкапа `V_BCKP` держать не нужно. Чистое небо по-прежнему помогает первому фиксу; поведение hot-start живёт внутри юнита.
- **DAC-out Grove-юниты не работают** — у S3 нет ЦАП; ничто на Grove это не вернёт.
- **Горячая замена — осторожно.** Grove-порты не рассчитаны на hot-swap; выключать питание перед втыканием юнита или добавить последовательные резисторы на SDA/SCL.
