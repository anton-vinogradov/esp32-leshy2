# Длительная работа и self-test · historical R1

`H3.6.3` проведён ревью. Устройство не обещает автономность или uptime в часах: для долгой работы подключается USB-PD, а 24/48 часов остаются длительностью испытаний H8.

Цель проектирования до физических измерений — `0…35 °C`, не паспортная гарантия. При 35 °C H6 должен получить не хуже `16,713 K/W` для quiet и `5,446 K/W` для тяжёлого voice RX.

В `Настройки → Безопасность → Полный self-test` доступны `24 часа`, `48 часов` по умолчанию и `только при запуске`. Изменение применяется после следующего физического `KILL → RUN`. Эта проверка fault-plane прерывает работу, но не повреждает железо. Настройка не меняет watchdog, thermal FAULT_KILL или TX-lease.
