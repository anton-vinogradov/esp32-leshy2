# Leshy2 — Roadmap

*Читать на: [English](roadmap.md) · **Русский***

Практичный план для **Leshy2** — портативного мультидиапазонного РЧ-устройства с открытым исходным кодом («полевой инструмент»). Это преемник [esp32-leshy](https://github.com/anton-vinogradov/esp32-leshy), который является прошивочным форком [ESP32-DIV](https://github.com/cifertech/ESP32-DIV). Причина для новой платы: у ESP32-DIV v2 нет 5 GHz Wi-Fi. Цель: максимум возможностей в разумных пределах за честную цену, целевой BOM около **115-150 USD**.

## Где мы сейчас

- **Архитектура зафиксирована (2026-08-08).** Это всё ещё **стадия дизайна** — **железо пока не собрано**.
- Мозг — **ESP32-C5** (один RISC-V MCU с нативным Wi-Fi 2.4 + 5 GHz и BLE). Прошивка будет портирована с кодовой базы ESP32-S3 (leshy).
- Следующий конкретный шаг — **схема в KiCad**.

## Фазы

### 1. Архитектура — готово

- [x] Выбрать мозг: **ESP32-C5** (один чип, нативный 2.4 + 5 GHz Wi-Fi + BLE)
- [x] Зафиксировать набор бортового РЧ: **3x nRF24L01+PA/LNA**, **CC1101**, **Si4732**, **SA868-U**
- [x] Зафиксировать аудиотракт: аналоговый line-out (Si4732 / SA868) -> усилитель класса D **PAM8302** -> небольшой динамик
- [x] Зафиксировать дальний TX: **Meshtastic поверх LoRa SX1262**, на плате
- [x] Зафиксировать дисплей: **3.5″ IPS TFT (ST7796, 320×480) по SPI** (на общей шине радио, CS через 138 + DC)
- [x] Зафиксировать расширение: **1× порт Grove HY2.0-4P (I²C)** (M5 I²C-юниты)
- [x] Зафиксировать питание: **2S 18650**, собственный PMIC (зарядник BQ25xxx + CH224K USB-C PD + power-path, buck 5V/3A, LDO 3.3V)
- [x] Зафиксировать антенны: **8 на борту** (LoRa теперь на плате); один аппаратный TX-live светодиод на каждый передающий тракт (RX-светодиода нет); антенна GPS — на u-blox-модуле

### 2. Схема в KiCad — следующий шаг

Собирается лист за листом. Начинаем с питания, затем MCU и его шины, затем каждый РЧ-тракт.

- [ ] **Сначала питание:** 2S 18650 -> зарядник BQ25xxx + CH224K USB-C PD + power-path -> buck 5V/3A -> LDO 3.3V
- [x] **C5 + шины** (Лист 2, [hardware/c5-buses](../hardware/c5-buses/c5-buses.ru.md)): ESP32-C5 (PSRAM), SPI (microSD + SX1262 + CC1101 + 3× nRF24 + ST7796, chip-select через дешифратор 74HC138), I2C (Si4732 + u-blox GPS + расширитель PCA9555 + Grove), UART (SA868), поворотный энкодер + кнопки, нативный USB
- [x] **РЧ-тракт — 3x nRF24L01+PA/LNA** (Лист 3, [hardware/rf](../hardware/rf/rf.ru.md)): фикс brownout = буферный 100-220 µF + 100 нФ на VCC каждого модуля; CSN через 138, связанный CE, IRQ опросом
- [x] **РЧ-тракт — CC1101** sub-GHz (Лист 3): 300-928 MHz OOK/FSK; CS через 138, GDO0 напрямую; опциональный РЧ-свитч, чтобы свести его диапазоны в одну SMA
- [x] **РЧ-тракт — SX1262 (LoRa)** на плате (Лист 3): E22-900M22S +22 dBm; NSS через 138, BUSY напрямую, DIO1 опросом, NRESET на PCA9555
- [ ] **РЧ-тракт — Si4732** приёмник (HF-вход с ESD/кламп-защитой — без ручного тумблера; изоляция через режимный sleep; аналоговый line-out)
- [ ] **РЧ-тракт — SA868-U** рация (управление по UART, PTT, аналоговое аудио)
- [ ] **Аудио:** усилитель PAM8302 + динамик (MCU не в аудиотракте)
- [ ] **Расширение:** 1× порт Grove I²C (M5 I²C-юниты; Grove I²C-хаб при нескольких сразу)
- [ ] **Индикация + I/O:** статусный WS2812, аппаратные детекторы огибающей TX-live (только на передающих трактах, 0 GPIO), зуммер, IR TX/RX, microSD

### 3. Разводка PCB

- [ ] **4-слойная** плата (JLCPCB JLC7628, импеданс +-10%)
- [ ] **Весь РЧ на экранированных модулях u.FL** — это снижает риски первой итерации
- [ ] РЧ-дорожки с контролем импеданса
- [ ] Размещение: **антенны сверху**, разъёмы расширения по бокам или сзади
- [ ] Земля питания и РЧ; буферные конденсаторы прямо рядом с модулями nRF24

### 4. Первая итерация PCB

- [ ] Заказать PCB (шаг для мейкера)
- [ ] Спаять и собрать (шаг для мейкера)
- [ ] Запуск (bring-up): проверить шины питания, загрузку C5 и каждую шину
- [ ] **Честное ожидание: 1 рабочая итерация + 1 доводочная итерация**

### 5. Портирование прошивки (S3 -> C5)

- [ ] Портировать код leshy с ESP32-S3 (Xtensa) на **ESP32-C5 (RISC-V)**
- [ ] Wi-Fi 2.4 + 5 GHz — 5 GHz уровня **Marauder** (скан, deauth, флуд beacon / probe, снифинг management-фреймов)
- [ ] Драйверы для каждого РЧ-тракта: 3x nRF24, CC1101, Si4732, SA868-U
- [ ] Ограничения мощности LoRa по регионам: EU433 +10 dBm, EU868 +14 dBm, 869.4-869.65 MHz +27 dBm при рабочем цикле 10%, US915 +30 dBm с перескоком по частоте
- [ ] Драйвер бортовой LoRa SX1262, u-blox GPS (NMEA по I²C), логирование PCAP на microSD, модули Grove (RFID2 NFC, RTC, IMU / компас)
- [ ] Ввод текста по BLE (длинный текст набирается на телефоне в приложении Meshtastic)

### 6. Настройка антенн (VNA)

- [ ] Настроить каждую из 8 бортовых антенн с помощью **VNA** (ручной шаг для мейкера)

### 7. Полевые испытания

- [ ] Проверка времени работы (лёгкий режим ~9 ч, активный ~3.6 ч, пики TX ~2.5 ч)
- [ ] Проверка дальности: голос SA868 (~3-5 км на открытой местности), Meshtastic (город 2-5 км, прямая видимость 10-15 км)
- [ ] Проверка каждого РЧ-тракта в реальных условиях

## Что намеренно вне области задачи

- **Захват / инъекция WPA-handshake на 5 GHz / уровень Pineapple.** Для этого нужен Linux, которого мы намеренно избегаем ради времени работы от батареи. 5 GHz остаётся только уровня Marauder.
- **Полноспектровое прослушивание голоса через SDR.** Голосовые провалы примерно на 108-430 MHz и 480-860 MHz (airband AM 118-137, VHF/UHF NFM вне 433/446) потребовали бы RTL-SDR плюс мини-Linux.
- **Широкополосное глушение.** Это незаконно (US Communications Act, раздел 333; EU RED).
- **TX на 27 MHz.** Si4732 работает только на приём.
- Это **не HackRF** — нет непрерывного покрытия 1 MHz-6 GHz с произвольным TX.
