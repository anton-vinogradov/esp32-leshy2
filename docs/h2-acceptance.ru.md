# H2-R2.1.5 · Итог production-схемы

[English](h2-acceptance.md) · [Главная](../README.ru.md) · [Роадмап](roadmap.ru.md) · [Схемы](schematics.ru.md)

**Статус:** ✅ проведено ревью 31 августа 2026 года. H2 теперь содержит полную
логическую production-схему R2 и синхронизированную границу железа и прошивки.
Это не разрешает размещение и трассировку PCB, закупку или производство.

## Результат

| Evidence | Результат ревью |
|---|---:|
| Native-проекты / граф sheets | 3 / 23 |
| Вычислительные домены | 6 |
| Точные MPN-группы / product positions | 242 / 1 197 |
| Группы на платах / явные non-PCBA группы | 237 / 5 |
| Устанавливаемые позиции / физические pins | 1 187 / 4 327 |
| Канонические nets | 826 |
| Подключённые логические endpoints / явные NC | 4 065 / 258 |

| Межпроектные / межлистовые nets | 51 / 236 |
| KiCad ERC | 0 ошибок / 0 предупреждений во всех 3 проектах |

Три native-root — `LESHY2-UI-R2`, `LESHY2-RF-R2` и
`L2-DISP-ADP-001-B`. Каждая устанавливаемая позиция имеет точную идентичность
символа и footprint. Каждый логический контакт сводится к канонической net или
явному no-connect. Каждый межпроектный сигнал проходит через зарегистрированную
границу разъёма; случайных RF или приватных локальных шин через M1 нет.

## Граница железа и прошивки

Машинная сверка охватывает все шесть вычислительных доменов, точную карту из
173 строки, 51 межпроектную и 236 межлистовых nets. Четырнадцать различающихся
имён — явные conditioned или multiplexed границы, а не скрытые несовпадения.
Прошивка fail-closed импортирует текущий H2-контракт; её R2 H2 sync-gate открыт.

## Чего H2 не доказывает

- размещение PCB, медную трассировку, return paths, controlled impedance и финальный DRC;
- evidence реальных деталей, разъёмов и фабрики из H5;
- поведение после трассировки: thermal, RF, SI, механика и корпус из H6;
- физический bring-up и HIL из H7/H8.

Это последующие gates, а не пропуски production-схемы. Заказ ровно одного
собранного прототипа остаётся заблокирован до прохождения H3, H4, H5, H6 и
прошивочного first-spin gate на одном неизменяемом кандидате.
