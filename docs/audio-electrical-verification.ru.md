# Электрическая проверка аудио

[English](audio-electrical-verification.md) · [На главную](../README.ru.md) · [Схемы](schematics.ru.md) · [Виртуальная проверка](virtual-verification.ru.md)

H3.3.2 проверяет весь аналоговый тракт: внутренний/гарнитурный микрофон и RX → ES8311 → гарнитура/динамик, плюс регулируемую подачу codec audio в выбранный SA818S-V или SA818S-U. Это расчёт серийных деталей; акустика, шум разведённой платы и RF immunity остаются измерениями H8.

## Захват и микрофоны

- Независимые bias-фильтры дают каждой капсуле `1.886410…2.087758 В`; замкнутый на землю TRS-контакт больше не просаживает внутренний микрофон.
- `33 кΩ` перед MIC1P/MIC1N убраны: они отнимали `-16.258 dB`. Серийные `0 Ω` теперь повторяют референс ES8311, а PGA остаётся программируемым `0…30 dB`.
- Безопасный старт — `0 dB`; до HIL для громкого входа действует cap `21 dB`. Публичные пределы шума не заменяют измерение собранной платы.

## Гарнитура

Разъём — CTIA/AHJ, mono dual-ear + microphone, не stereo codec. Даже при консервативных `17.600 мкФ` эффективной ёмкости нижняя граница равна `239.357 Гц` для 16 Ω и `168.146 Гц` для 32 Ω: голос сохраняется, low bass проверяется физически. Detect-only P02 имеет минимум `0.830537·VCC`; ток DC через вставленные 16-Ω наушники не выше `0.331 мА`.

## Динамик

В реальном углу `4 Ω −15% = 3.400 Ω` теоретический BTL-предел равен `1.587581 Вт`, ниже 2-Вт рейтинга динамика. PAM8302A требует до `576.453 мА`; ветка получает `625.000 мА`. При 85 °C расчётный junction `99.679 °C`, но сам динамик допускает только 50 °C локально, поэтому выше этого порога playback аппаратно/программно mute, а остальные функции могут продолжаться по будущему H3.6 envelope. SD включается не раньше 10 мс после valid rail.

## Подача audio в SA818S-V/U

`Vishay CRCW0402160KFKED` вместе с 2,2 кΩ/10 нФ даёт `10.454…12.797 мВ RMS` против опубликованной цели `10.000 мВ для обоих SA818S. Калибровка идёт только вниз codec volume; выбор audio никогда не включает PTT.

## Перепроверка 3V3_MAIN

Исправленный worst case — `2493.000 мА` из 2500 мА принятого режима и `28.359%` до гарантированного hardware limit. Normal display/backlight теперь `200 мА`, audio — `625 мА`; fault-порог подсветки больше не считается рабочей нагрузкой.

Итоговая аналоговая конфигурация добавляет `0.0436 USD` на устройство при количестве 100. **H3.3.2 проверено; текущий точный маркер — `H3.6.1`.**
