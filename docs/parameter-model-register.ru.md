# Параметры и модели R2

[Главная](../README.ru.md) · [Роадмап](roadmap.ru.md) · [English](parameter-model-register.md)

Статус `H3-R2.0.2`: ✅ reviewed. Это точный реестр входов будущих расчётов для принятой R2-схемы, а не старой R1: каждый тип компонента связан с MPN, экземплярами, листами, источником параметров, классом модели и владельцем проверки.

## Покрытие

- `242` групп компонентов: `237` на платах и `5` явно внешних/финально устанавливаемых.
- `1187` устанавливаемых позиций; у всех `242` групп есть владелец H3.
- У `68` групп уже есть структурированные параметры; `174` стоят в явной очереди извлечения, а не получают выдуманные значения.
- Назначены `242` кандидата метода; точный метод, tolerance и applicability фиксирует следующий шаг `H3-R2.0.3`.

## Ограниченные находки источников

Для `CS0805-R27J-S` (`C108271`) и `3225-27.00-10-10-10/A` (`C518151`) точная идентичность и фабричный маршрут подтверждены JLCPCB, но полной manufacturer-controlled модели corners пока нет. Они остаются входами `H3-R2.3`; недостающие параметры нельзя молча предполагать. Это не запрос на замену компонента.

> Placement, routing, закупка и печать не разрешены. Следующий шаг — воспроизводимо зафиксировать методы, допуски и pass/fail rules.
