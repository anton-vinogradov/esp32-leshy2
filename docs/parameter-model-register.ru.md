# Параметры и модели R2

[Главная](../README.ru.md) · [Роадмап](roadmap.ru.md) · [English](parameter-model-register.md)

Статус `H3-R2.0.2`: ✅ reviewed. Это точный реестр входов будущих расчётов для принятой R2-схемы, а не старой R1: каждый тип компонента связан с MPN, экземплярами, листами, источником параметров, классом модели и владельцем проверки.

## Покрытие

- `251` групп компонентов: `245` на платах и `6` явно внешних/финально устанавливаемых.
- `1208` устанавливаемых позиций; у всех `251` групп есть владелец H3.
- У `75` групп уже есть структурированные параметры; `176` стоят в явной очереди извлечения, а не получают выдуманные значения.
- Назначены `251` кандидата метода; точный метод, tolerance и applicability фиксирует следующий шаг `H3-R2.0.3`.

## Ограниченные находки источников

У реестра не осталось factory-catalog-only источников параметров. Для точного `3225-27.00-10-10-10/A` (`C518151`) привязаны пределы TX3 по ESR, drive и температуре; прежний `CS0805-R27J-S` заменён фабрично доступным `RS-06L2R70FT` (`C323265`) после расчёта подсветки H3-R2.3.

> Placement, routing, закупка и печать не разрешены. Следующий шаг — воспроизводимо зафиксировать методы, допуски и pass/fail rules.
