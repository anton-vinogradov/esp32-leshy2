# FND-0072 — target README содержали инженерную хронику

- Статус: **Закрыто исправлением и `DEC-0060`**
- Обнаружено: 2026-08-17
- Затрагивает: четыре корневые EN/RU страницы hardware/firmware,
  `DEC-0011`, пользовательский вход в документацию

## Наблюдение

Корневые README формально назывались target-документами, но их нижние половины
снова превратились в current-state ledger. В них последовательно пересказывались
`DEC/REV/FND`, промежуточные кандидаты, незакрытые HIL-гейты и причины изменения
распиновки. Примером служил один абзац, который одновременно перечислял
`DEC-0051…0057`, `DSP-0004/0005`, `AUDIO-0001/0002`, `PHY-0001`, `MEC-0001` и
`FND-0069`.

Технически информация была верной, но нарушала разделение `DEC-0011`:

- пользователь не видел цельного образа готового продукта;
- target page требовала знания внутренней системы идентификаторов;
- текущие блокеры дублировались и быстро устаревали;
- широкая pinout-таблица плохо читалась на узком экране;
- целевое свойство смешивалось с историей его выбора.

## Исправление

Четыре target README переписаны как product landing pages:

1. продуктовые возможности и гарантии описаны языком результата;
2. инженерная зрелость оставлена в `docs/status/current-state.*.md`;
3. решения и доказательства остались в `docs/review/`;
4. аппаратная вертикальная diagram и exact MPN сохранены;
5. широкая pinout-таблица заменена раскрываемым списком групп;
6. firmware получила компактную вертикальную state-flow диаграмму;
7. regression запрещает возвращение `DEC/REV/FND/IMP` chronology и раздела
   `Development state / Состояние разработки` в target pages.

Никакое принятое свойство продукта при исправлении не удалено. Изменился слой
представления и место хранения инженерного контекста.
