# FND-0005 — неверная распиновка аудиовыходов Si4732 в tsCircuit

- Статус: **Закрыто исправлением; проведено ревью в `REV-0002E`**
- Серьёзность: hardware blocker для Si4732 audio
- Обнаружено: 2026-08-15
- Исправлено: 2026-08-15

## Несоответствие

Текущий `hardware/tscircuit/audio.tsx` объявлял выводы Si4732-A10 так:

- pin 1 — `ROUT`;
- pin 2 — `LOUT`;
- pin 3 и pin 16 — `NC`.

По datasheet 16-SOIC правильная карта другая:

- pin 1 — `LOUT/DFS`;
- pin 2 — `GPO3/DCLK`;
- pin 3 — `GPO2/INTB`;
- pin 16 — `ROUT/DOUT`.

В результате один суммирующий резистор был подключён к цифровому `GPO3/DCLK`, правый аудиоканал оставался неподключённым, а узел `SI_AUDIO` не мог считаться корректным моно-выходом приёмника.

## Исправление

В `audio.tsx` моносумма переведена на pin 1 и pin 16. Комментарий источника pin map исправлен. Архивные legacy-документы не переписываются: они сохраняют исходное состояние, а настоящая находка объясняет расхождение.

## Проверка

- source trace использует только `pin1=LOUT/DFS` и `pin16=ROUT/DOUT`;
- `pin2=GPO3/DCLK` больше не включён в аналоговую сумму;
- сгенерированный readable netlist подтверждает: `RsumL` приходит с pin 1, `RsumR` — с pin 16, обе ветви сходятся в `SI_AUDIO`;
- финальная схема всё равно требует ERC и проверки реального символа/footprint перед производством.
