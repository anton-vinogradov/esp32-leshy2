# FND-0001 — единственный GP-SPI C5 занят двумя ролями

- Статус: **Открыто**
- Серьёзность: архитектурный блокер
- Обнаружено: 2026-08-15

## Наблюдение

Legacy-дизайн одновременно назначает general-purpose SPI ESP32-C5 двум несовместимым ролям:

1. SPI-slave транспорта S3↔C5;
2. SPI-master локальной шины трёх nRF24.

По datasheet ESP32-C5 предоставляет один general-purpose контроллер SPI2, который поддерживает master- и slave-режимы, но не две независимые одновременные роли.

## Ограничение

Владелец проекта переоткрыл именно nRF24-часть `DEC-0001`; IR остаётся C5. Если будет принят `IMP-0021/A`, nRF24 остаются на текущей стороне S3 и конфликт исчезает структурно. Если владельцем остаётся C5, этап 3 обязан выбрать межпроцессорный транспорт вне GP-SPI либо отдельно доказать программную/внешнюю реализацию второй SPI-роли.

## Кандидаты

- UART между S3 и C5; SPI2 C5 полностью отдаётся nRF24.
- Программный SPI для nRF24; SPI2 остаётся межпроцессорным slave.
- Внешний SPI bridge.
- Выделенный SDMMC-host S3 ↔ SDIO-slave C5; GP-SPI C5 полностью отдаётся nRF24 (`IMP-0002`).
- Все три полнофункциональных nRF24 принадлежат S3 на общей SPI2 с независимыми reset-safe CE states и measured shared-bus HIL (`AUD-0003`, **⚠️ `IMP-0021/A`**).

Кандидаты пока не являются решениями.
