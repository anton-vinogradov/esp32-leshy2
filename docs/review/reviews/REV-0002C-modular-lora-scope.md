# REV-0002C — ревью scope внешнего модульного LoRa

- Статус: **Историческое; пересмотрено `REV-0002D` после `DEC-0008`**
- Этап: 2, завершённый подшаг
- Дата: 2026-08-15
- Решение: `DEC-0007`
- Проверенные предложения: `IMP-0007`, `IMP-0008`

## Пререквизиты

> Последующее уточнение: обязательность E22 carrier в этом ревью отменена `DEC-0008`; актуальный результат проверки находится в `REV-0002D`.

- этап 1 имеет статус «Проведено ревью»;
- `DEC-0002` разрешает all-in-one с подключаемыми расширениями;
- `DEC-0003` задаёт безопасный TX-дефолт для каждого backend;
- `DEC-0005` запрещает считать функционально суженный вариант экономией без потерь;
- `DEC-0006` уже удалил бортовой GNSS и разрешил внешний M5Stack GNSS;
- `INV-0001` содержит полный legacy-класс `C-LORA-*` и `C-GPS-*` как кандидаты.

## Проверено

- владелец явно выбрал поддержку и Cardputer LoRa Cap, и сменного LoRa-модуля;
- U214 использует SX1262 по SPI, добавляет AT6668 GNSS и официально ограничен 868–923 MHz;
- E22-900M22S сохраняет прямое SPI-управление SX1262 и заявленное окно 850–930 MHz;
- общий `EXT-RF14` содержит необходимые SPI/control/UART/I²C/power сигналы на уровне scope;
- готовые UART/AT LoRaWAN Units не признаны функционально эквивалентными raw SX1262;
- один активный backend сохраняет модульность без незаказанной сложности двух одновременных RF-трактов;
- отдельный GPS Unit из `DEC-0006` не удалён молча, а сохранён альтернативой встроенному GNSS U214;
- base и full-kit cost разделены; предварительная экономия U214 не выдана за подтверждённую котировку.

## Результат

Scope-подшаг внешнего LoRa проведён ревью. Бортовой LoRa исключён из целевой основной PCB; приняты прямой U214 и сменная wideband carrier через один модульный профиль, с одним активным LoRa backend.

Открытых вопросов уровня scope нет. Этап 2 в целом остаётся в работе из-за остальных групп возможностей и находок.

## Что этим ревью не подтверждено

- окончательный connector MPN, GPIO и pin budget;
- допустимое соединение `5V_IN/5V_OUT`, protection, inrush и power budget;
- hot-plug, механическое удержание и ресурс сочленений;
- схема E22 reference carrier и её реальная цена;
- coexistence, conducted RF, sensitivity, spurs, EMC и thermal;
- firmware backend implementation и автоматическое обнаружение;
- сертификация и разрешённые региональные профили.

Это выходы этапов 3–9, а не открытая часть решения о scope.
