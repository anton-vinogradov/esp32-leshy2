# REV-0002G — ревью переноса `IMP-0010` на сводный pin budget

- Статус: **Проведено ревью**
- Область: последовательность этапов 2–3 и межрепозиторное распространение
- Дата: 2026-08-16
- Решение: `DEC-0012`

## Проверено

- `IMP-0010` остаётся явно открытым предложением без принятого варианта;
- новый owner decision сейчас не запрашивается;
- будущий gate требует полного системного pin/GPIO/resource budget, а не локального подсчёта `U13`;
- `FND-0006` и `FND-0007` остаются открытыми и не названы закрытыми;
- этап 2 может продолжить функциональные требования без преждевременной pin-map;
- этап 3 получил pin/resource budget как обязательный выход;
- hardware/firmware current-state страницы одинаково описывают перенос;
- target README не изменены: открытое предложение не стало свойством готового продукта;
- относительные ссылки изменённых документов проходят проверку.

## Результат

Распространение `DEC-0012` проведено ревью. Статус самого System/UI capability-среза остаётся **«В работе»** до завершения его требований; `IMP-0010` возвращается на решение только после сводного pin budget этапа 3.
