# Leshy2 — состав и бюджет

*Читать на: [English](bom.md) · **Русский***

Из чего собрано устройство и сколько это стоит. Цены — **ориентировочные, за штуку** для ручного прототипа (стадия проектирования, ничего ещё не заказано). Это оценка для планирования, не прайс; на объёме большинство строк дешевеет.

Leshy2 считается как **платформа + возможности**, а не одним плоским списком:

- **Платформа** — то, что на плате есть всегда: два мозга, дисплей, питание, шины и бортовой I/O. Купил это — и у тебя уже есть инструмент **2.4 ГГц Wi-Fi + BLE** (нативно на ESP32-S3), экран и SD-логгер. Больше ничего не нужно.
- **Возможности** — каждое радио добавляешь за его цену. Нужна рация? +~$13. Нужна разведка 5 ГГц? Добавь ESP32-C5 (~$7). Что не нужно — не ставишь, и цена падает вместе с ним.

> **Итог:** электроника ≈ **$108–125**, вся сборка (с PCB + корпус) ≈ **$135–160**. Два чипа, девять антенн, каждый РЧ-тракт собран из «голого» кремния.

## Стоимость крупными блоками

| Блок | ≈ USD |
|------|:----:|
| **Платформа** (S3 + обвязка линка C5 + дисплей + питание + шины + бортовой I/O) | ≈ 47 |
| **Возможности** (все радио, GPS, аудио) | ≈ 61 |

## Платформа — ≈ $47

Есть всегда. Это инструмент, который получаешь ещё до добавления хоть одного радио.

| Компонент | Роль | ≈ $ |
|------|------|:--:|
| ESP32-S3-WROOM-1U-N8R2 | **главный мозг** — UI, дисплей, все проводные радио, SD, шины; нативно **2.4 ГГц Wi-Fi + BLE**; 36/36 ног | 4 |
| ST7796 4.0″ IPS TFT (320×480, SPI) + ёмк. тач | цветной дисплей + тач + водопад на аппаратном скролле | 9 |
| Питание (лист 1) | 2S 2×18650, boost-заряд BQ25887, S-8252A, рейлы MP2315×2/TPS7A2033, master-тумблер | 23 |
| 3× PCA9555 · 74HC138 · вентиль 74AHC1G | расширители медленных линий (0x20/0x21/0x22) · дешифратор CS · вентиль nRF24-IRQ | 1.3 |
| microSD · кнопки RESET/BOOT/PTT · энкодер · WS2812 · buzzer · янтарные TX-LED | бортовой I/O + лог PCAP + честные светодиоды «в эфире» | 9 |
| 2× USB-C · антенна S3 2.4 ГГц SMA · пассив | J1→S3 (заряд+данные), J2→C5 (только данные) | 1 |

Внешняя **SMA**-антенна на S3 (не чип-антенна) — именно она даёт фронтенду 2.4 ГГц реальную дальность. Это то самое радио, что идёт с платформой даром.

## Возможности — ≈ $61

Добавляешь только нужное. Каждая строка — самодостаточное радио (модуль + своя настроенная антенна).

| Возможность | Компоненты | ≈ $ |
|------|------|:--:|
| **Разведка 5 ГГц** | сопроцессор ESP32-C5-WROOM-1U (единственный ESP32 с нативным 5 ГГц) + dual-антенна 2.4/5; линк SPI3 + DRDY к S3 | 7 |
| **Рация (голос TX/RX)** | SA868-U 2 Вт 433/446 NBFM + UHF-антенна | 13 |
| **2.4 ГГц «сырое»** | 3× nRF24L01+PA/LNA + 3 антенны — параллельный скан полосы, mousejack | 10 |
| **LoRa / Meshtastic** | SX1262 (E22-900M22S, +22 дБм) + антенна | 9 |
| **Sub-GHz 315/433/868/915** | CC1101 (голый + кварц + балун) + SP4T SKY13414-485LF + 4 матч-сети + антенна | 8 |
| **GPS** | модуль u-blox по UART, онборд + антенна | 6 |
| **Приём HF/CB/FM + аудио** | Si4732-A10 (только RX) + усилитель PAM8302 + динамик + гнездо наушников + телескоп | 8 |
| **Де-страп GPIO45** | eFuse `set_flash_voltage 3.3V` — освобождает ногу под carrier-sense CC1101 | 0 |

**GPS — обычный UART-модуль (~$6)**, онборд — без премиального GPS-компонента.

**Шаг eFuse стоит $0 по компонентам** — это разовый заводской прожиг, а не деталь. Он возвращает ногу (GPIO45) под прерывание carrier-sense CC1101 GDO2.

## Куда уходят деньги

Несколько строк — почти вся стоимость электроники; полезно знать, где деньги:

1. **Питание (~$23)** — ячейки + 2S-boost-зарядник + три рейла. Одни только качественные 18650 ~$10.
2. **Рация SA868-U (~$13)** — единственный 2-ваттный голосовой трансивер здесь.
3. **3× nRF24L01+PA/LNA (~$10)** — три модуля для параллельного покрытия 2.4 ГГц.
4. **Дисплей ST7796 (~$9)** — 4.0″ IPS-панель.
5. **LoRa SX1262 (~$9)** и **ESP32-C5 (~$7)** — mesh-радио и сопроцессор 5 ГГц.

## Честные оговорки

- **Ориентировочно.** Цены компонентов не зафиксированы на стадии проектирования; каждая цифра ±30 %.
- **За штуку.** Это хоббийные количества; модули (nRF24, CC1101, SX1262, SA868, C5) заметно дешевеют на объёме.
- **Два чипа, плата больше.** Две РЧ-секции и шина линка — это более крупная 4-слойная PCB.
- **Не учтено:** припой, провод, приборы, время VNA на настройку девяти антенн и твой труд.
- **Корпус варьируется сильнее всего** — 3D-печать почти бесплатна, фрезерованный — нет.
