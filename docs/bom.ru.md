# Leshy2 — состав и бюджет

*Читать на: [English](bom.md) · **Русский***

Из чего собрано устройство и сколько это стоит. Цены — **ориентировочные, за штуку** для ручного прототипа (стадия проектирования, ничего ещё не заказано), сгруппированы по шести листам схемы. Это оценка для планирования, не прайс; на объёме большинство строк дешевеет.

> **Итог:** электроника ≈ **$105**, вся сборка (с PCB + корпус) ≈ **$120–150** — в исходном целевом диапазоне.

## Куда уходят деньги

Пять компонентов — ~60 % стоимости электроники, полезно знать, где деньги:

1. **u-blox GPS (~$14)** — I²C-нативный модуль дороже дешёвого UART-GPS; именно он держит бюджет ног чистым ([почему](pin-budget.ru.md)).
2. **Рация SA868-U (~$10)** — единственный 2-ваттный голосовой трансивер здесь.
3. **2× 18650 (~$10)** — качественные ячейки; ноунейм дешевле.
4. **Антенны (~$15 суммарно по двум РЧ-листам)** — 8 трактов, у каждого своя настроенная антенна.
5. **Модуль LoRa SX1262 (~$7)**.

## Честные оговорки

- **Ориентировочно.** Цены компонентов не зафиксированы на стадии проектирования; каждая цифра ±30 %.
- **За штуку.** Это хоббийные количества; модули (nRF24, CC1101, SX1262, GPS) заметно дешевеют на объёме.
- **Не учтено:** припой, провод, приборы, время VNA на настройку 8 антенн и твой труд.
- **Корпус варьируется сильнее всего** — 3D-печать почти бесплатна, фрезерованный — нет.
