# Питание Leshy2

[English](power-architecture.md) · [На главную](../README.ru.md) · [Принципиальные схемы](schematics.ru.md)

Это итоговая архитектура питания готового устройства. Она проверяется по полной netlist, которую экспортирует сам KiCad.

## Источники

- Единственный внешний источник — основной USB-C S3: только sink, до 30 Вт (5 В fallback, 9 В × 3 А или 15 В × 2 А). Сервисные USB C5 и RP2354B питание устройства не принимают.
- Автономный источник — два съёмных защищённых 18650, последовательно, рабочий диапазон 6,0–8,4 В. Для работы от аккумуляторов нужны оба элемента.

## Вход, заряд и аккумуляторы

`USB-C` → **Texas Instruments TPS25751DREFR** → **Texas Instruments BQ25798RQMR** → `NVDC_SYS`.

`2× 18650` → два независимых предохранителя 5 А → **Analog Devices MAX17320G20+T** + **Texas Instruments MSPM0C1106SDGS20R** → встречно включённые силовые MOSFET → зарядник/`NVDC_SYS`.

## Формируемые шины

| Выход | Тракт | Назначение |
|---|---|---|
| `AON_SAFE_3V3` | `NVDC_SYS` → TPS629203 → TPS25961 | Всегда включённая safety-логика |
| `3V3_MAIN` | `NVDC_SYS` → TPS564252 → TPS25974 | Процессоры, UI и обычная логика |
| `VVOICE_4V` | `NVDC_SYS` → TPS564252 → TPS25974 | Только голосовой RF-тракт |
| `5V_U214_PROTECTED` | `NVDC_SYS` → TPS564252 → TPS259470 | Съёмный U214 LoRa Cap |
| `5V_UNIT_PROTECTED` | тот же buck → отдельный TPS259470 | M5 Unit; отказ одной ветви не питает другую |

## Результат H2.5.1

✅ **Проведено ревью:** 17 критичных силовых цепей прослежены в реальной KiCad-netlist. UI, RF и LoRa Cap содержат соответственно 387, 678 и 27 уникально обозначенных компонентов; коллизий references нет.

Исправлен fabrication-blocker: локальные `R1/C1/U1` разных дочерних листов заменены детерминированными диапазонами по номеру листа.
