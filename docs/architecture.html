Обзор

Что устройство умеет

Шесть функциональных групп. Цвет метки = направление тракта.

Разведка / атаки

  • WiFi 2.4 + 5 ГГц: скан, deauth, beacon/probe, сниф mgmt
  • 2.4 raw (3× nRF24): mousejack, скан, анализатор
  • Sub-GHz (CC1101): replay OOK/FSK, RSSI-гейгер
  • BLE · IR · NFC (RFID2)

Слушать голосом 🔊

  • CB 27 МГц + весь КВ + FM (Si4732, AM/SSB)
  • Рации 433/446 (SA868): слушать и говорить
  • Живой звук в динамик, MCU вне тракта

Слать в эфир 📡

  • Meshtastic (LoRa): текст на километры
  • Голос 433/446 (2 Вт)
  • Sub-GHz TX · WiFi/BLE beacons

Спектр глазами

  • Водопад/RSSI на AMOLED (тёмный фон = экономия)
  • Видно «где занято» без демодуляции

Вспомогательное

  • GPS · геотег · время (cap)
  • NFC 13.56 · IR-пульты
  • PCAP-лог на SD · пеленг (IMU+компас)

Расширяемость

  • Cap-слот — любой Cardputer ADV капп
  • 2× Grove — любой M5 Unit
  • I²C-мукс без конфликта адресов

Лист схемы 1

Питаниедизайн готов

2× 18650 (2S) → PD-заряд → power-path → рельсы +5 В / +3V3 / +3V3A. Полный netlist и номиналы — в hardware/power/power.md репозитория.

Лист схемы 2

ESP32-C5 + шиныследующий

Мозг и распределение шин. Модуль берём с PSRAM (буфер AMOLED + запас под порт прошивки S3→C5).

MCU
ESP32-C5-WROOM-1 (PSRAM-вариант) — RISC-V, WiFi 2.4+5 + BLE нативно
SPI
microSD + cap (общая шина, разд. CS) + CC1101 + 3× nRF24
QSPI
AMOLED-дисплей (RM67162) — отдельная 4-битная шина, ×4 к SPI
I²C
Si4732 (управление) + PCA9548-мукс (Grove #1) + Grove #2
UART
SA868-U (управление) + GNSS каппа + Grove #2 (опц.)
GPIO
энкодер + кнопки, IR TX/RX, WS2812, buzzer, SA868 PTT, cap RESET/INT/BUSY, TX-live входы

Смена экрана на QSPI AMOLED снимает дисплей со SPI — это разгружает главную SPI-шину и даёт плавный водопад (QSPI ×4). Проверить esp_lcd QSPI-драйвер под RM67162 на C5.

Лист схемы 3

РЧ-трактыпланируется

Четыре самодельных тракта на экранированных u.FL-модулях, у каждого своя антенна (общего РЧ-свитча нет). Разверни узел слева для деталей.

nRF24 ×3

  • 2.4 raw · SPI · 3 антенны
  • mousejack, параллельный скан

CC1101

  • 300–928 МГц · SPI · 1 антенна
  • OOK/FSK, RSSI-гейгер

Si4732

  • 27/КВ/FM · I²C · телескоп
  • только приём, аналог-аудио

SA868-U

  • 433/446 · UART · 1 антенна
  • рация RX+TX 2 Вт
Лист 3 · РЧ

nRF24 ×3планируется

Диапазон
2.4 ГГц raw (2400–2525), RX+TX +20 dBm (PA/LNA)
Шина
SPI (общая), 3× CS + CE/IRQ на GPIO
Антенны
3 отдельные (параллельный скан всего бэнда)
Роль
mousejack, скан каналов, raw-пакеты — то, чего WiFi C5 не видит

Критичный brown-out: модули PA/LNA дают импульсный ток → 100–220 µF + 100 нФ прямо у VCC каждого.

Лист 3 · РЧ

Si4732планируется

Диапазон
CB 27 МГц + весь КВ + СВ/ДВ (AM/SSB/CW) + FM 64–108 — только приём
Шина
I²C (управление); аналоговый line-out в аудио-тракт
Антенна
телескоп 1–1.7 м (λ/4@27МГц ≈ 2.75 м); switch отключения+заземления + ESD на входе

Приёмный тракт → только синий RX-светодиод, без янтарного TX.

Лист 3 · РЧ

SA868-Uпланируется

Диапазон
433/446 МГц NBFM, RX и TX до 2 Вт (апгрейд с SA818 1 Вт)
Шина
UART (управление) + PTT на GPIO; аналоговое аудио (RX и mic-TX)
Легалка
446 PMR ≤ 0.5 Вт ERP; 5 Вт только на ham 70 см по лицензии — режем прошивкой
Лист схемы 4

Аудиопланируется

Аудио полностью аналоговое, MCU вне тракта. У C5 нет ЦАП — свой звук MCU только по I2S.

Лист схемы 5

Расширенияпланируется

M5-совместимость: 1 cap-слот (копия Cardputer ADV EXT-14P) + 2 универсальных Grove-порта. Поддержка Units и Caps; Modules (M5Bus) и HATs — другой разъём, не берём.

Cap-слот — EXT 2.54-14P (1:1)

Референс-капп: M5 Cap LoRa-1262 — SX1262 (+22 dBm) + GNSS ATGM336H с внутренней керамикой → Meshtastic и GPS одним модулем.

Grove ×2

Port 1
I²C + мукс PCA9548 → RFID2 NFC + RTC + IMU/компас + будущие (без коллизий адресов)
Port 2
гибкий I²C / UART / GPIO / ADC — принимает M5 Unit типов A/B/C
Лимит
DAC-out юниты не работают (у C5 нет ЦАП); 5 В питание / 3.3 В сигнал
Лист схемы 6

Индикация / IOпланируется

Два светодиода на каждую антенну + служебный IO.

RX (синий)
WS2812, управляется прошивкой — MCU знает активный тракт (цепочка на 1 GPIO)
TX (янтарный)
аппаратный детектор огибающей на передающих трактах — честное «в эфире» даже при зависшей прошивке
RX-only
Si4732 получает только синий RX (передачи нет)
Прочее IO
buzzer, IR TX/RX, кнопки + поворотный энкодер, microSD (PCAP)

Честные пределы

Сознательные компромиссы ради батареи, размера и закона.

5 ГГц = Marauder-класс

  • скан / deauth / beacon / сниф — да
  • захват WPA-хендшейков / injection / Pineapple — нет (нужен Linux)

Дыра голосового приёма

  • ~108–430 и ~480–860 МГц голосом не слышно
  • нужен RTL-SDR + мини-Linux — вне области

Не HackRF

  • нет сплошного 1 МГц–6 ГГц с произвольным TX
  • набор фикс-трактов вместо этого

27 МГц — только приём

  • Si4732 не передаёт
  • антенна большая → телескоп + switch/ESD

Широкополосного глушения нет — незаконно (US §333, EU RED) и построено не будет.
