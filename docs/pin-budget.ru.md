# Leshy2 — Бюджет ног по режимам работы

*Читать на: [English](pin-budget.md) · **Русский***

Leshy2 работает **с одним радио-режимом за раз**, поэтому радио делят небольшой пул GPIO. Пик по ногам — это самый тяжёлый один режим, а не сумма всех радио. ESP32-C5 даёт примерно **19 доступных GPIO** после flash/PSRAM и USB.

![Бюджет ног по режимам](img/pin-budget.svg)

**База — задействована всегда (11 ног):** SPI ×3, CS-дешифратор 74HC138 ×3, I²C ×2, энкодер ×2, WS2812 ×1. **Дисплей:** 1-бит SPI +1 · QSPI +5. **Пул режима:** до 4 общих ног, переиспользуются между взаимоисключающими режимами.

Ниже — для каждого режима, зачем каждая нога **именно в нём**. На 1-бит SPI у всех режимов запас; на QSPI режим `LoRa + GPS` не влезает (20 > 19), а несколько режимов встают впритык.

### Меню / ожидание

Ног: **SPI 12 / QSPI 16** (из 19)

| Нога | Зачем в этом режиме |
|---|---|
| `SPI SCK/MOSI/MISO` (3) | шина SPI → microSD |
| `74HC138 A/B/C` (3) | дешифратор CS → SD |
| `I²C SDA/SCL` (2) | сенсоры · RTC · RFID · кнопки (через хаб) |
| `Encoder A/B` (2) | навигация по меню |
| `WS2812` (1) | поантенные статус-светодиоды |
| `Дисплей` (SPI +1 / QSPI +5) | рисует UI этого режима |
| `pool` | — |

### 2.4 скан (nRF24×3)

Ног: **SPI 13 / QSPI 17** (из 19)

| Нога | Зачем в этом режиме |
|---|---|
| `SPI SCK/MOSI/MISO` (3) | шина SPI → nRF24 ×3 + microSD |
| `74HC138 A/B/C` (3) | дешифратор CS → nRF24 ×3, SD |
| `I²C SDA/SCL` (2) | сенсоры · RTC · RFID · кнопки (через хаб) |
| `Encoder A/B` (2) | навигация по меню |
| `WS2812` (1) | поантенные статус-светодиоды |
| `Дисплей` (SPI +1 / QSPI +5) | рисует UI этого режима |
| `pool · CE` | взводит RX на «атакующем» модуле; два других держат CE=1 (чистый приём) |

| Нога | Зачем в этом режиме |
|---|---|
| `SPI SCK/MOSI/MISO` (3) | шина SPI → microSD |

### LoRa + GPS

Ног: **SPI 16 / QSPI 20** (из 19) ❌

| Нога | Зачем в этом режиме |
|---|---|
| `SPI SCK/MOSI/MISO` (3) | шина SPI → LoRa SX1262 (кэп) + microSD |
| `74HC138 A/B/C` (3) | дешифратор CS → LoRa cap, SD |
| `I²C SDA/SCL` (2) | сенсоры · RTC · RFID · кнопки (через хаб) |
| `Encoder A/B` (2) | навигация по меню |
| `WS2812` (1) | поантенные статус-светодиоды |
| `Дисплей` (SPI +1 / QSPI +5) | рисует UI этого режима |
| `pool · BUSY` | линия занятости SX1262 — ждать перед каждой SPI-операцией |
| `pool · DIO1` | прерывание RX/TX-done (или поллинг) |
| `pool · GPS-TX` | поток NMEA от GNSS |
| `pool · GPS-RX` | конфиг в GNSS |
