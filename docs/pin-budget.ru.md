# Leshy2 — Бюджет ног по режимам работы

*Читать на: [English](pin-budget.md) · **Русский***

Устройство работает **с одним радио-режимом за раз**. Это делит GPIO на три честные группы — ноги, занятые в **каждом** режиме, ноги, **зарезервированные под радио** (припаяны к радио, переиспользуются по режимам), и **шина I²C**. Плюс опциональный 74HC138 — и это весь бюджет. Хаба нет; поантенные светодиоды «в эфире» — чисто аппаратные (0 GPIO). У ESP32-C5 около **19 доступных GPIO**.

![Слои бюджета ног](img/pin-budget.svg)

## 1. Занято в каждом режиме

Горит, что бы ты ни делал.

| Линия | Ног | Зачем |
|---|:--:|---|
| `Encoder A/B/SW` | 3 | навигация — поворот (A/B) и нажатие (SW) |
| `SPI SCK/MOSI/MISO` | 3 | общая дата-магистраль для всех SPI-радио и SD |
| `SD chip-select` | 1 | выбирает SD-карту на этой магистрали (логи, профили) |
| **Подытог** | **7** | + дисплей |

**Дисплей** добавляет **+1** (1-бит SPI: только DC, делит шину) или **+5** (QSPI: своя 4-битная шина) → **SPI 8 / QSPI 12**.

## 2. Зарезервировано под радио (переиспользуется по режимам)

Эти GPIO **припаяны к управляющим линиям радио** (CS, CE, BUSY, DIO1, …). В меню они простаивают на спящих радио, но **занять их под другое нельзя** — поэтому они зарезервированы. Фокус «одно радио за раз» в том, что **одни и те же** ноги в разных режимах служат разным радио, поэтому резервируешь **самый тяжёлый один режим**, а не сумму всех радио.

| Режим | Юзкейс | Что берёт из радио-ног | Ног |
|---|---|---|:--:|
| Меню / ожидание | меню, настройки, статус | — | 0 |
| WiFi 2.4/5 | скан / deauth / сниф (радио в C5) | — | 0 |
| 2.4 скан (nRF24×3) | 3 nRF24 сниффят 2.4 ГГц параллельно | 3× nRF24 CS | 3 |
| Mousejack (nRF24 TX) | инъекция на 2.4 ГГц (один передаёт) | 3× CS + CE | 4 |
| Sub-GHz (CC1101) | replay пультов; RSSI-гейгер | CS + GDO0 | 2 |
| Рации (SA868) | слушать/говорить 433/446 (PTT) | UART + PTT | 3 |
| LoRa + GPS | текст Meshtastic + позиция — пик | CS + BUSY + DIO1 + GPS-UART | 5 |
| Слушать КВ/FM (Si4732) | приём CB/КВ/FM (AM/SSB) | RST (+ шина I²C) | 1 |
| Ключи (RFID2) | чтение/эмуляция карт 13.56 МГц | — (шина I²C) | 0 |
| ИК-пульты | клон/replay ИК-пультов | IR TX + RX | 2 |
| | | **пик = LoRa + GPS** | **5** |

То есть эта группа резервирует **5 ног** — не ~15 (сумму), потому что переиспользуются; и не меньше, потому что LoRa+GPS требует 5 одновременно.

## 3. Шина I²C

**2 ноги.** SDA/SCL — это *шина* (подтяжки + Si4732 + RFID2 + разъёмы Grove на одной меди), поэтому её **нельзя переиспользовать** как радио-ноги выше — её 2 ноги заняты, пока хочешь **приём КВ/CB/FM (Si4732), считыватель RFID или M5-юниты Grove**. Убрать все три → убрать шину I²C.

## Опция: CS-дешифратор 74HC138 — +1 нога

Превращает 3 ноги в 8 чистых point-to-point chip-select. При «одном режиме за раз» помогает только режиму nRF24; пик (LoRa) — всего 2 CS, поэтому суммарно стоит **+1**. Без него прямые CS делят неты между чипами (спящий обязан отпускать линию — небольшой SI-риск на первой плате). Держим ради чистой разводки; выкидываем ради ноги.

## Итоги

```
Занято всегда (энкодер+SPI+SD+экран) ...... SPI 8  / QSPI 12
Зарезервировано под радио (пик = LoRa) .... +5
Шина I²C (приём / RFID / Grove) ........... +2
                                            = SPI 15 / QSPI 19
+ 74HC138 (опция, чистые CS) .............. +1  = SPI 16 / QSPI 20
```

| Конфигурация | SPI | QSPI |
|---|:--:|:--:|
| только радио (без I²C, без 138) | 13 | 17 |
| + I²C (слушать / RFID / Grove) | 15 | 19 |
| + I²C + 138 (всё) | 16 | 20 |

## Премиум-экран (QSPI) — да, влезает

**QSPI со всем, что реально нужно (приём, RFID, Grove, LoRa) = 19 → ровно потолок 19.** 74HC138 — *единственное*, что выталкивает за край (до 20). Значит премиум-AMOLED реален — просто **не ставим опциональный 138** и делаем chip-select прямыми. Реклейм USB не нужен. Единственная плата — прямые CS на общих нетах (аккуратная разводка).

## Смена режимов — задержки и почему нет фризов

Смена = усыпить старое → пере-мукс зарезервированных GPIO (мкс) → поднять новое. Ожидание — это старт; он не фризит UI (радио ждут по таймеру, процессор свободен).

| Вход в режим | Из сна | Ощущение |
|---|:--:|---|
| nRF24 / CC1101 / LoRa / WiFi | ≤5 мс | мгновенно |
| Si4732 AM/FM | ~200 мс | короткое «настройка…» |
| Рация SA868 | ~0.3–1 с | короткий спиннер |
| Si4732 **SSB** (патч) | ~1.2 с | спиннер + прогресс-бар |

Прошивка: неблокирующий init на одноядерном C5 (фоновая задача); **nRF24 держим тёплым**, **CC1101 и Si4732 спят** между использованиями; **pre-warm по наведению**; конденсатор SA868 **1 µF (не 10 µF)** режет TX fade-in.
