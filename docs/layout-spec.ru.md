# Leshy2 — спека отрисовки раскладки

*Читать на: [English](layout-spec.md) · **Русский***

Фиксированная спека для (пере)рисовки рендера двухплатной раковины ([`layout-clamshell.en.svg`](img/layout-clamshell.en.svg) / [`.ru.svg`](img/layout-clamshell.ru.svg)). Это **артефакт этапа 5 наравне с самим рендером**: рендер обязан всегда воспроизводиться из этой спеки, и при расхождении **спека главнее — рендер перегенерируется**. Футпринты — реальные тела деталей из даташитов, выбранных в [листах tscircuit](../hardware/tscircuit/).

## 1. Холст и структура

- **Портрет, три ряда.** Ряд 1 = главная плата (**снаружи-перёд** | **внутри**); Ряд 2 = плата C5 (**внутри** | **снаружи-зад**); Ряд 3 = боковой **разрез** + таблица антенн + легенда.
- **Двуязычно** — по SVG на EN и RU, геометрия одна.
- **В масштабе** — обе платы **~75 × 150 мм**, один фиксированный px/мм; каждая деталь — в реальном футпринте (§6–§7).

## 2. Две платы

- **Размер платы: ~75 × 150 мм каждая; ~34 мм полная толщина раковины.**
- **Раковина.** Внутренние грани смотрят друг на друга — компоненты в зазоре, защищены. Внешние грани несут только дисплей + управление (перёд) и батарею (зад), **плюс SMA-антенны вдоль верха каждой**.
- **Межплатный зазор.** Высота стоек — **≥ самой высокой детали внутренней грани**, чтобы детали двух плат расчистились: `h_A(x,y) + h_B(x,y) ≤ зазор` везде. **Модули nRF24 — самые высокие внутри** — при **низком монтаже** (припаяны / короткие пины, как у DIV, **не** на высоком 2×4-сокете) они всего **~5–7 мм**, поэтому зазор следует **замеренным на DIV зазором 11 мм** (высокий сокет добавил бы ~8 мм и пробил бы бюджет толщины — не использовать).
- **Крепёж.** Четыре угловых отверстия **M2.5**, совмещённые на обеих платах; **каждая деталь и антенна уведены от них**.

## 3. Виды и правило зеркала

- Рисуются четыре грани: главная снаружи, главная внутри, C5 внутри, C5 снаружи, плюс разрез.
- **Внутренние грани — это вид СЗАДИ, зеркалятся лево↔право.** Внутренняя грань — это перёд, отражённый относительно вертикальной оси: **верх / низ на месте, лево и право меняются**. Деталь на **левой** кромке устройства поэтому рисуется **справа** на виде внутри (и наоборот) — оба вида описывают одну физическую плату, а не «просвет насквозь».
- **Разрез** — стек толщины перёд→зад (дисплей · главная плата · зазор · плата C5 · батарея), зазор ≥ самой высокой внутренней детали (§2).

## 4. Интерфейс vs компонент (цвет)

- **Интерфейс — синяя рамка.** Всё, с чем контактирует человек: **вкручивает антенну, вставляет провод, нажимает, засовывает карту, двигает, слушает / говорит, трогает экран.** **Холдер батареи** — интерфейс (вставляют банки) — зелёная заливка + синяя рамка.
- **Компонент — серая рамка.** Внутренние, не трогают: МК, радио, ИС, дешифраторы, `BT1`, межплата.
- **Индикаторы** — свои значки, не рамки: TX-live LED = мелкие янтарные точки, RGB-статус = R/G/B-пирог.

## 5. Правила размещения

- **Снаружи-перёд — только то, на что смотрят или что жмут:** дисплей, D-pad, BACK / OPTIONS, энкодер + F1 / F2 (левый борт), PTT + STOP (правый борт), динамик + микрофон (низ), ряд LED. Антенны вдоль верха.
- **Снаружи-зад:** холдер батареи (по центру) + антенны вдоль верха.
- **Все разъёмы / переключатели / сервис-кнопки — на ВНУТРЕННИХ гранях**, каждый **на кромке платы, куда выходит** (деталь посреди платы не дотянется до прорези), через прорези корпуса.
- **Стрелка направления у каждого внешнего порта** — мелкая красная стрелка **от детали в поле, никогда на подпись** (проверяется). Порты нижней кромки → стрелка вниз; боковой кромки → наружу в свою сторону.

## 6. Пропорции — реальные футпринты

Каждый бокс ≈ **реальный футпринт** (§7), в один общий масштаб — **разъём никогда не крупнее модуля**. Формы:

| Форма | Рисуется как | Примеры |
|---|---|---|
| `module` | скруглённый прямоугольник (намёк на РЧ-экран) | WROOM, nRF24, SA868, LoRa, GPS |
| `IC` | мелкий прямоугольник | CC1101, Si4732, PCA9555, зарядники, LDO |
| `connector-rect` | мелкий прямоугольник у кромки | USB-C, microSD, джек, Grove, слайд |
| `connector-round` | круг (намёк на шестигранник) | SMA |
| `cylinder` | скруглённая капсула | банка 18650 |
| `holder` | крупный скруглённый прямоугольник | холдер 2× 18650 |
| `button-square` | мелкий квадрат | D-pad, энкодер, тактовые кнопки |
| `led` | точка / пирог | TX-live, RGB |
| `display` | крупный прямоугольник (врезка активной области) | ST7796 |

## 8. Автопроверки — все обязаны быть 0 до использования рендера

Генератор парсит собственный готовый SVG и отклоняет рендер, проваливший любую (никогда не на глаз):

1. **Наложения** — нет пересечений прямоугольников / подписей.
2. **Доступность** — каждый **интерфейс** (синий) на **внутренней** грани сидит у кромки платы (закопанный разъём / переключатель / кнопка не дотянется до корпуса).
3. **Стрелка-на-подписи** — ни одна стрелка направления не попадает на подпись.
4. **Межплатный зазор** — зазор в разрезе ≥ самой высокой внутренней детали.
