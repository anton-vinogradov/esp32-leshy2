# Контракт владения аппаратными блоками

Статус документа: **частично принят**, не «Проведено ревью».

| Блок | Владелец | Состояние решения |
|---|---|---|
| 3× nRF24L01+ | не выбран | три полнофункциональных тракта приняты; physical owner выводится zero-based synthesis по `DEC-0027` |
| IR TX | ESP32-C5 | целевое требование принято; транспорт не доказан, `DEC-0001` |
| IR RX | ESP32-C5 | целевое требование принято; транспорт не доказан, `DEC-0001` |
| Native BLE | ESP32-S3 | принято `DEC-0021`; C5 BLE default-off |
| C5 Wi-Fi/IEEE 802.15.4 | ESP32-C5 | принято на уровне controller ownership `REQ-W5-0001` |
| S3 Wi-Fi 2.4/ESP-NOW | ESP32-S3 | принято на уровне controller ownership `REQ-W24-0001` |
| Остальные блоки | назначаются только после `CAP/CON/RES` | требуется пройти zero-based synthesis этапа 3 |

Этот файл не наследует назначения из legacy-документов автоматически.
