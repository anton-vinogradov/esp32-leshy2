# Leshy2 — Железо

*Читать на: [English](hardware.md) · **Русский***

Подробный справочник по железу **Leshy2** — открытому портативному многодиапазонному РЧ-наладоннику («полевому инструменту»). Преемник [esp32-leshy](https://github.com/anton-vinogradov/esp32-leshy), который является прошивочным форком [ESP32-DIV](https://github.com/cifertech/ESP32-DIV). Весь дизайн переведён на единый мозг **ESP32-C5** (нативный Wi-Fi 2.4 **и** 5 ГГц + BLE), вокруг которого заметно больше радио.

> 📌 **Стадия проектирования. Железа пока нет.** Архитектура зафиксирована (2026-08-08); следующий шаг — схема в KiCad. Распиновка и точные номиналы появятся после проверки на реальном железе. Весь бортовой РЧ — на экранированных u.FL-модулях ради снижения рисков первого спина PCB. Плата 4-слойная (JLCPCB JLC7628), проектируется в KiCad; антенны настраиваются вручную по VNA.

## Антенны

У Leshy2 **8 бортовых антенн**, по одной на РЧ-тракт. **Общего РЧ-свитча между трактами нет**, поэтому у каждого тракта своя отдельная антенна — никакого складывания разных трактов на один разъём. У GPS-модуля **своя** встроенная антенна, отдельно от этих восьми.

**Бортовые (8):**

1. **ESP32-C5** — двухдиапазонный Wi-Fi 2.4 / 5 ГГц + BLE (одна двухдиапазонная антенна; у C5 один РЧ-порт и работа по одному диапазону за раз).
2. **nRF24 #1** — 2.4 ГГц.
3. **nRF24 #2** — 2.4 ГГц.
4. **nRF24 #3** — 2.4 ГГц.
5. **CC1101** — sub-GHz 300–928 МГц. (Опциональный РЧ-свитч, идея от M5 Cap CC1101, может сложить *собственные* полосы CC1101 в один SMA — это внутри одного тракта, не между трактами.)
6. **Si4732** — большой телескоп для HF / CB (только приём).
7. **SA868-U** — 433 / 446 МГц UHF.
8. **SX1262 (LoRa)** — 868 / 915 МГц, на плате.

**GPS:** **встроенная керамика** u-blox-модуля — на самом модуле; модуль на плате на шине I²C (Лист 5).

**Размещение:** восемь антенн — **сверху**; разъёмы расширителей — по бокам или сзади.

**Защита HF-входа Si4732:** пассивный **ESD/кламп** (опционально встречно-параллельный диодный ограничитель) на HF-входе. **Ручного выключателя нет** — де-сенс от собственных передатчиков убран режимной эксклюзивностью (Si4732 не слушает, пока передаёт другое радио), а антенна снимается откручиванием SMA.

**Антенна 27 МГц большая.** Четвертьволновка на 27 МГц — около **2.75 м**, полноразмерный штырь на наладоннике нереален. План — **телескоп 1–1.7 м** или **укороченный/нагруженный штырь**.

## Поантенная индикация

Каждый **передающий** тракт получает **один аппаратный TX-live светодиод**, чтобы с одного взгляда видеть, какая антенна реально излучает:

- **TX — янтарь (аппаратный детектор огибающей).** Честный «в эфире»: зажигается от реального РЧ-излучения, поэтому горит **даже если прошивка зависла**. Софтом **не управляется** и стоит **0 GPIO**. Специально минимально яркий.

**Поантенного RX-светодиода нет** — детектор на приёмном входе сажал бы его чувствительность, а активный тракт и так виден на экране. Поэтому только-приёмные тракты (Si4732) вообще без светодиода. Общее состояние устройства показывает единственный общий **WS2812** и экран.

| Тракт | TX-live светодиод (янтарь) |
|-------|:--:|
| ESP32-C5 (Wi-Fi/BLE) | ✓ |
| nRF24 #1 | ✓ |
| nRF24 #2 | ✓ |
| nRF24 #3 | ✓ |
| CC1101 (sub-GHz) | ✓ |
| SA868-U (UHF-голос) | ✓ |
| SX1262 (LoRa) | ✓ |
| Si4732 (HF/CB/FM, только RX) | — |

## Шины

Цифровая периферия сидит на шинах ESP32-C5, всё на 3.3 В — level shifter на SPI / I²C / UART не нужен. Два исключения: **WS2812** (его 5-вольтовый порог логической единицы требует буфера 3.3→5 В) и любой **5-вольтовый Grove-юнит** (за I²C-транслятором).

**SPI** — microSD, 3× nRF24, CC1101, бортовой SX1262 (LoRa) и **дисплей ST7796**. Chip-select каждого генерит дешифратор **74HC138** (3 GPIO → 8 CS-линий), а не по GPIO на каждый; дисплей добавляет одну линию **DC**. Так как активно одно радио за раз, дисплей и радио не конфликтуют за шину. Фреймбуфер (320×480×2 ≈ 300 КБ) держит C5 с PSRAM.

**I2C** — управление Si4732, **u-blox GPS** (0x42), **расширитель I/O PCA9555** (медленные управляющие линии, см. ниже) и Grove-порт: RFID2 NFC (0x28), RTC, IMU / компас и будущие юниты по адресам. Несколько разом — в **Grove I²C-хаб** на единственном порту.

**UART** — SA868-U (управление). **PTT** рации едет на расширителе PCA9555. (GPS больше не на UART — он на I²C.)

**GPIO (прямые)** — IR TX/RX, статусный WS2812, энкодер A/B, CC1101 GDO0, nRF24 CE, линия LoRa BUSY, DC дисплея и адресные линии 74HC138. Медленные линии (кнопка энкодера, SA868 PTT / PD, Si4732 RST, LoRa NRESET + T/R, RESX + подсветка дисплея, аудио-мукс, enable 74HC138, INT/CD зарядника, buzzer) сидят на **PCA9555** по I²C за 0 ног хоста; LoRa DIO1 и nRF24 IRQ опрашиваются по SPI. См. [pin-budget.md](pin-budget.ru.md).

## Расширение

Leshy2 **совместим с M5** на уровне **M5 Grove I²C-юнитов**. M5 **Caps** (шина Cardputer EXT), **Modules** (16-pin стек M5Bus) и **StickC HATs** используют другие разъёмы и **не поддерживаются**. Два жёстких лимита порта: он **только I²C**, и **DAC-out юниты не работают**, потому что у C5 нет ЦАП.

### Бортовая LoRa (SX1262)

Дальний mesh Meshtastic — это **raw SX1262-модуль на плате** (класс E22-900M, u.FL): общая SPI-шина, **свой CS через 74HC138** и две управляющие линии — **BUSY** и **DIO1**. На плате mesh всегда доступен ценой одной постоянной антенны в верхнем ряду. GPS вынесен с этого тракта на I²C (ниже), поэтому не стоит лишних GPIO; см. [pin-budget.md](pin-budget.ru.md).

### GPS (u-blox, I²C)

Координаты даёт маленький **u-blox GPS** (класс SAM-M8Q) **на плате** на шине **I²C**, со своей встроенной антенной. Общение по I²C (DDC/NMEA) вместо UART даёт ему ехать на уже имеющейся шине за **0 лишних GPIO** — один из ходов, что держит тесный бюджет ног в рамках (см. [pin-budget.md](pin-budget.ru.md)).

### Grove-порт (1× I²C)

Один порт **Grove HY2.0-4P**, разведён как шина **I²C** (питание 5 В, сигналы 3.3 В). Держит любые M5 I²C-юниты — RFID2 NFC, RTC, IMU / компас, сенсоры — по адресам, а при нескольких сразу — через **Grove I²C-хаб**. (u-blox GPS — на плате на той же шине, порт ему не нужен.) Второй независимый Grove-порт выкинут: это +2 GPIO, которых тесный бюджет не даёт, а всё наше расширение и так I²C.

**Юниты, доступные по Grove:**

- **NFC:** RFID2 Unit (WS1850S, 13.56 МГц, MIFARE / NTAG, I2C-адрес 0x28).
- **RTC:** метки времени для логов PCAP.
- **IMU + компас:** пеленгация.

## Аудио-тракт

Аудио **полностью аналоговое**, MCU **не в тракте**:

```
Si4732 / SA868-U  →  line-out (аналог)  →  усилитель класса D PAM8302  →  маленький динамик
```

Si4732 и SA868-U выдают реальный аналоговый голос/аудио на line-out, который питает усилитель класса D **PAM8302**, качающий маленький динамик. У ESP32-C5 **нет аналогового ЦАП**, поэтому звук от MCU мог бы выйти только по **I2S** — его намеренно держат вне приёмного аудио-тракта.

## Питание

Leshy2 питается от **2× 18650 в 2S** (около **7.4 В**, около **18 Wh**) со **своим PMIC**:

- 2S **boost**-зарядник **BQ25887** — заряжает от обычных **5 В** USB (без PD), I²C с балансировкой и ADC-гейджем
- **Вход USB-C 5 В** (CC-подтяжки; без PD-чипа)
- **Power-path нет** — бэки на узле BAT; единственный вкл/выкл — жёсткий **master-тумблер**
- **Buck 5 В / 3 А** + **LDO 3.3 В** на рейлы

**Почему свой PMIC:** готовые **односекционные M5-модули не подходят** — нужен 2S и PD-sink. **IP5306 отвергнут** (слабый boost и авто-отключение под малой нагрузкой).

**Фикс brownout nRF24:** PA/LNA-модули дёргают импульсный ток, поэтому каждому — **100–220 мкФ bulk + 100 нФ на VCC**, чтобы питание не проседало.

**Время работы (ориентировочно):**

| Режим | Время |
|-----|--------|
| Лёгкий | ~9 ч |
| Активный | ~3.6 ч |
| Пики TX | ~2.5 ч |
