# Leshy2 — Железо

*Читать на: [English](hardware.md) · **Русский***

Подробный hardware-справочник по **Leshy2** — портативному многодиапазонному РЧ-наладоннику с открытым исходным кодом («полевой инструмент»). Это преемник [esp32-leshy](https://github.com/anton-vinogradov/esp32-leshy), который является прошивкой-форком [ESP32-DIV](https://github.com/cifertech/ESP32-DIV). Весь дизайн переходит на единый мозг **ESP32-C5** (нативный Wi-Fi 2.4 **и** 5 GHz + BLE) и заметно больше радио вокруг него.

> 📌 **Стадия проектирования. Железа пока нет.** Архитектура зафиксирована (2026-08-08); следующий шаг — схема в KiCad. Распиновки и точные номиналы появятся после проверки на реальном железе. Всё бортовое РЧ размещено на экранированных модулях с u.FL, чтобы снизить риски первой итерации PCB. Плата 4-слойная (JLCPCB JLC7628), спроектирована в KiCad; антенны настраиваются вручную по VNA.

## Антенны

У Leshy2 **7 бортовых антенн**, по одной на каждую РЧ-цепь, плюс собственные антенны съёмного кэпа. **Общего РЧ-свитча между цепями нет**, поэтому у каждой цепи своя отдельная антенна — разные цепи не сводятся на один разъём.

**Бортовые (7):**

1. **ESP32-C5** — двухдиапазонный Wi-Fi 2.4 / 5 GHz + BLE.
2. **nRF24 #1** — 2.4 GHz.
3. **nRF24 #2** — 2.4 GHz.
4. **nRF24 #3** — 2.4 GHz.
5. **CC1101** — sub-GHz 300–928 MHz. (Опциональный РЧ-свитч, идея взята из M5 Cap CC1101, может свести *собственные* диапазоны CC1101 на один SMA — это внутри одной цепи, а не между цепями.)
6. **Si4732** — большой телескопический штырь для HF / CB (только приём).
7. **SA868-U** — UHF 433 / 446 MHz.

**На съёмном кэпе:**

- **LoRa RP-SMA** для SX1262.
- **Внутренняя керамическая GPS-антенна** для GNSS (внутри кэпа).

**Размещение:** антенны идут **сверху**; разъёмы расширителей — по бокам или сзади.

**Защита HF-входа Si4732:** на HF-входе стоит **свитч отключения + заземления** и **ESD-защита**, так что фронтенд можно безопасно изолировать и заземлить.

**Антенна на 27 MHz большая.** Четвертьволновый штырь на 27 MHz — около **2.75 m**, поэтому полноразмерный штырь для наладонника непрактичен. План — **телескопический штырь 1–1.7 m** или **укороченный / нагруженный штырь**.

## Поантенная индикация

У каждой антенны **два LED**, чтобы с одного взгляда видеть, какая цепь принимает, а какая реально излучает:

- **RX — синий (WS2812, управляется прошивкой).** MCU знает, какая цепь активна, и зажигает для неё синий LED.
- **TX — янтарный (аппаратный детектор огибающей).** Это **честный индикатор «в эфире»**: он срабатывает от реального РЧ-излучения, поэтому горит **даже если прошивка зависла**. Программой не управляется.

**У цепей только на приём TX LED нет.** Цепь Si4732 (HF / CB / FM, только приём) получает синий RX LED, но без янтарного TX LED.

| Цепь | RX LED (синий) | TX LED (янтарный) |
|-------|:--:|:--:|
| ESP32-C5 (Wi-Fi/BLE) | ✓ | ✓ |
| nRF24 #1 | ✓ | ✓ |
| nRF24 #2 | ✓ | ✓ |
| nRF24 #3 | ✓ | ✓ |
| CC1101 (sub-GHz) | ✓ | ✓ |
| Si4732 (HF/CB/FM, только RX) | ✓ | — |
| SA868-U (UHF-голос) | ✓ | ✓ |

## Шины

Цифровая периферия делит три шины от ESP32-C5. Поскольку C5 работает на 3.3 V, для сигналов 3.3 V преобразователь уровней не нужен.

**SPI** — TFT-дисплей, microSD, 3× nRF24, CC1101 и SX1262 съёмного кэпа. У каждого устройства свой chip-select (CS). **SPI кэпа делит бортовую SPI-шину microSD** (тот же приём, что у Cardputer), на **отдельном CS**.

**I2C** — интерфейс управления Si4732, мультиплексор PCA9548 на Grove Port 1 и I2C-модули Grove за мультиплексором (RFID2 NFC на 0x28, RTC, IMU / компас). Grove Port 2 тоже может нести I2C.

**UART** — SA868-U (управление), UART-пины кэпа и GNSS кэпа. Grove Port 2 тоже может нести UART. **PTT** у SA868 — отдельная линия GPIO.

**GPIO** — IR TX/RX, WS2812 LED, buzzer, кнопки и поворотный энкодер, PTT SA868, линии RESET / INT / BUSY кэпа и Grove Port 2, когда используется под GPIO / ADC.

## Расширение

Leshy2 **совместим с M5**, но только с **M5 Units и Caps**. M5 **Modules** (16-пиновый стек M5Bus) и **StickC HATs** используют другие разъёмы и **не поддерживаются**. Жёсткое ограничение на любом порту: **модули с выходом DAC не работают**, потому что у C5 нет DAC.

### Слот кэпа — реплика Cardputer ADV EXT-14P

Единственный слот кэпа — **точная реплика 1:1 шины Cardputer ADV EXT 2.54-14P** — 100% копия по электрике и разъёму. «Полная поддержка» кэпа означает эту шину-реплику плюс драйвер в прошивке, написанный под этот кэп.

Распиновка (2.54 mm, 14 пинов):

| Пин | Сигнал | Пин | Сигнал |
|:--:|--------|:--:|--------|
| P1 | RESET | P2 | 5V_IN |
| P3 | INT | P4 | GND |
| P5 | BUSY | P6 | 5V_OUT |
| P7 | SPI_SCK | P8 | I2C_SDA |
| P9 | SPI_MOSI | P10 | I2C_SCL |
| P11 | SPI_MISO | P12 | UART_RX |
| P13 | SPI_CS | P14 | UART_TX |

**Референсный кэп: M5 Cap LoRa-1262** (~14.50 USD). Несёт **SX1262** (+22 dBm, для Meshtastic) **и** **GNSS ATGM336H / AT6668** с внутренней керамической антенной — так что один кэп даёт сразу **Meshtastic и GPS**. Его SPI делит бортовую SPI-шину microSD на отдельном CS, ровно как позволяет распиновка выше.

### Порты Grove (2×)

Два порта **Grove HY2.0-4P**, сделаны максимально универсальными. Оба дают **питание 5 V** и **сигналы 3.3 V**.

- **Port 1 — шина I2C за мультиплексором PCA9548.** Мультиплексор держит I2C-модули (RFID2 NFC, RTC, IMU / компас и будущие I2C-модули) **без конфликтов адресов**.
- **Port 2 — гибкий I2C / UART / GPIO / ADC.** Принимает M5 Unit типов **A / B / C**.

**Модули, доступные через Grove:**

- **NFC:** RFID2 Unit (WS1850S, 13.56 MHz, MIFARE / NTAG, адрес I2C 0x28).
- **RTC:** метки времени для логов PCAP.
- **IMU + компас:** пеленгация.

## Аудиотракт

Аудио **полностью аналоговое**, и MCU **не в тракте**:

```
Si4732 / SA868-U  →  line-out (analog)  →  PAM8302 class-D amp  →  small speaker
```

Si4732 и SA868-U выдают настоящий аналоговый голос/аудио на line-out, который идёт на усилитель класса D **PAM8302**, качающий небольшой динамик. У ESP32-C5 **нет аналогового DAC**, поэтому любой звук, сгенерированный MCU, мог бы выйти только по **I2S** — его намеренно держат вне приёмного аудиотракта.

## Питание

Leshy2 питается от **2× 18650 в 2S** (около **7.4 V**, около **18 Wh**) со **своим PMIC**:

- зарядка аккумулятора **BQ25xxx**
- приёмник **USB-C PD** (**CH224K**)
- **Power-path**, чтобы устройство работало во время зарядки
- **Buck-преобразователь 5 V / 3 A** + **LDO 3.3 V** для шин питания

**Почему свой PMIC:** готовые **одноэлементные модули M5 не подходят** — дизайну нужны 2S и приёмник PD. **IP5306 отклонён** (слабый boost и автоотключение при малой нагрузке).

**Фикс просадки питания nRF24:** модули PA/LNA потребляют импульсный ток, поэтому у каждого модуля стоит **100–220 µF ёмкости + 100 nF на VCC**, чтобы питание не проседало.

**Время работы (приблизительно):**

| Режим | Время работы |
|-----|--------|
| Лёгкий | ~9 h |
| Активный | ~3.6 h |
| Пики TX | ~2.5 h |
